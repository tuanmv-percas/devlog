# ant-hustle

```
1. Gameplay VFX

GameplayVfx.cs — [NEW]
- Scene listener (GameEventsListener) that plays pooled particle effects through EffectService on block bump, dock landing, ant attach and block fill
- Hitstop on block fill (hitstopDuration, default 0 so it is off) with time scale restore on end or destroy
- Tints dock slots red with a pulse when one slot is left, the dock is full, or the level is lost (lastSlotDanger / fullDanger / lostDanger)
- Flashes the dock red on OnBlockRefused (refusedFlash, refusedFlashDuration)
- Inspector toggles antAttachEnabled, blockDockedEnabled, blockFilledEnabled, blockBumpEnabled, all off by default
- Added blockFireworkEnabled (on) and fireworkSize; the firework spawns at the block centre on OnBlockFilled, sized to the block width
- HalfExtents overload now also returns the block centre

GameplayParticleEffect.cs — [NEW]
- BaseParticleEffect subclass with chained SetTint, SetSize and SetDirection, resetting scale on OnGetFromPool

ParticleFx.cs — [NEW]
- Static helpers Play, Stop, StopEmitting, Tint(color, whiten) and ColorOf(block) for obstacle particle systems
- VfxMount detaches a particle system from its host so it outlives the host, and reattaches it on reuse

EffectKey.cs — [MOD]
- Added block_bump, block_docked, ant_attach, block_filled and block_firework keys

effects.config.asset — [MOD]
- Registered the five new effect prefabs under their keys

VfxBlockBump / VfxBlockDocked / VfxAntAttach / VfxBlockFilled.prefab — [NEW]
- Particle prefabs for the four gameplay events; the docked prefab keeps only the ring, smoke emission off

VfxBlockFirework.prefab — [NEW]
- Sand Block's completion firework, materials rebuilt on URP Particles/Unlit with the original textures

Art/Vfx/Materials (VfxCircle, VfxCloud, VfxRing, VfxSpark, VfxSparkle, VfxStar, VfxTwinkle, Firework/*) — [NEW]
- Particle materials for the gameplay and firework effects

ThirdParties/VFXLibrary textures — [NEW]
- circle, cloud, ring_shockwave, sparkle, star, magic star and spark textures from Epic Toon FX, JMO Cartoon FX Remaster and Super Confetti FX

Default Local Group.asset — [MOD]
- Added the gameplay VFX prefabs and the firework prefab to Addressables

Gameplay.unity — [MOD]
- Added the GameplayVfx object to the Gameplay scene

----------------------------------------------------------------------

2. Obstacle Animation and VFX (Hidden, Ice, Stack, Lock, Key)

HiddenObstacle.cs — [MOD]
- On reveal the ? mark punches, then pops, spins, lifts toward the camera and shrinks away
- Tapping a covered block wiggles it around the camera axis instead of sliding it sideways
- Plays revealVfx and a block-coloured sparkleVfx on reveal, detached through VfxMount; the block grows back in with overshoot

IceObstacle.cs — [MOD]
- Each layer lost lands reactDelay after the tap: punches the shell and pops the count label as it changes
- Last layer frees the block at once, swells and trembles the shell, then shatters; tapping the block away mid-swell just drops the shell
- Replaced breakEffect with crackVfx, revealVfx and sparkleVfx
- Tapping a frozen block wiggles it instead of sliding it

StackElement.cs — [MOD]
- Tube squashes along its mouth before pushing a block out and springs back with overshoot; the count punches as it changes
- New block is squeezed out of the mouth (ApplyExtrusion): back edge stays at the mouth until fully out, then slides into place with a landing squash
- Empty stack pops, spins and shrinks away with retireVfx; pushVfx plays on each push
- Replaced spawnDelay / spawnSlide / spawnGrow with pushDuration, mouthScale, landSquash and landDuration

KeyObstacle.cs — [MOD]
- Key sways gently on its block with an idle particle
- Launch pops and lifts, then flies to the lock on a jump arc with spin and a trail particle (flyDuration, jumpPower, flySpin, trailVfx)
- At the lock it pitches 90 degrees, slides along the lock's z axis into the keyhole, sinks, turns turnAngle and shrinks
- Swaps to the pair texture for its id via pairTextures; key particle renderers no longer receive that texture

LockElement.cs — [MOD]
- Replaced single body Renderer with a renderers array and pairTextures
- Bump now rattles the lock (rattleAngle / rattleDuration) as well as pushing it
- Unlock squashes the lock while the model's shackle Animation clip plays and holds open, then pops, spins and retires with unlockVfx and retireVfx
- Replaced keyTarget / KeyTargetLocal with keyhole / KeyholeLocal; added ForwardLocal and RightLocal for the key's approach
- Removed EaseInBack in favour of TweenShape

LockKeyColors.cs — [MOD]
- Added Pick(textures, id) and Apply(renderer, id, textures): sets _BaseMap with a white _BaseColor, falling back to the colour tint when no texture is set

TweenShape.cs — [NEW]
- Replays DOTween Punch and Shake curves on LitMotion so obstacle juice uses Sand Trip's numbers
- Added easing helpers OutBack, InBack, OutQuad, InQuad, InOutQuad and InOutSine

Block / BlockHidden / BlockIce / BlockKey / Lock / Stack.prefab — [MOD]
- Wired the new obstacle particle systems and animation fields

Obstacles VFX prefabs (VfxHiddenReveal, VfxIceCrack, VfxIceReveal, VfxKeyIdle, VfxKeyTrail, VfxLockUnlock, VfxLockRetire, VfxStackPush, VfxStackRetire) — [NEW]
- Particle prefabs ported from Sand Trip with URP materials

Art/Vfx/Materials/Obstacles and Art/Vfx/Textures/Obstacles — [NEW]
- VfxChunk, VfxGlow, VfxIceShard, VfxPuff, VfxQuestion, VfxRing, VfxSparkle, VfxTwinkle materials and fx_ice_shard / fx_question textures

ice.fbx / lock.fbx / newKey.fbx — [NEW]

BlockIce.prefab / BlockKey.prefab / Lock.prefab — [MOD]
- Switched to the new models and materials

4. Block Feel (squash, stretch, refused taps)

BlockVisual.cs — [MOD]
- Moving block stretches along its travel by speed and relaxes in traffic; braking into a slot flattens it, landing holds a beat then springs back
- Blocked tap stretches into the bump, flattens on contact and springs back on the way home; the hit block flattens along the hit as it is pushed
- Added PlayRefuseWiggle for covered blocks (refuseAngle, refuseDuration, refuseVibrato)
- Cutting a root motion short (StopRootHandle / ClearRootMotion) puts the root back upright and full size
- Replaced blockedMoveSpeed / minBlockedMove / blockedReturnDuration with bumpOutDuration, bumpBackDuration, bumpPenetration and bumpRecoilOvershoot
- Hit and shake now use TweenShape punch/shake (hitDuration, hitVibrato, hitElasticity, shakeDuration, shakeStrength, shakeVibrato)
- Added PlayRootMotion(duration, bind, finish) and PlayGrowIn(duration, overshoot); removed PlayThaw and PlayReveal

SquashMotion.cs — [NEW]
- Shared Offset(target, direction, amount) helper for axis squash, after Sand Trip's

Block.cs — [MOD]
- A tap whose exit route cannot be built now shakes the block and raises BlockRefused instead of returning silently
- Covered-block taps raise OnBlockCoveredTapped instead of OnBlockRefused

Dock.cs / DockSlot.cs — [MOD]
- Added DockSlot.SetTint(color) using a MaterialPropertyBlock on _TintColor or _BaseColor
- Added then removed the dock-wide refuse shake (Dock.PlayRefused, DockSlot.PlayRefuse); the tapped block still shakes and the dock still flashes red

GameplayLevelLoader.cs — [MOD]

ScreenCover.cs — [NEW]

TutorialController.cs — [MOD]

7. Tracking (level_start / level_finish)

LevelShape.cs — [NEW]
- Reads a level's block count (Stack boxes included), distinct colours and obstacle types present (hidden, ice, stack, lock_key)

GameTracker.cs — [MOD]
- AttemptStarted holds level_start until LevelBuilt reports the board for that level; a retry sends at once
- level_start now carries numberOfObjectives, numberOfColors and mechanics from LevelShape instead of zeros
- An attempt that ends before its board is built still sends a bare level_start, keeping one start per finish for APS
- A loss sends objectivesLeftPercent: share of blocks not yet cleared, counted by ObjectiveCleared

GameplayLevelLoader.cs — [MOD]
- ReportToTracker calls GameTracker.LevelBuilt with LevelShape.Of(level) and counts OnBlockFilled as ObjectiveCleared
```
