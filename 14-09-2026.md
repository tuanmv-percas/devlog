# bird-story

```
1. Tutorial System

TutorialService.cs — [NEW]
- Listens for the level-ready milestone and runs the per-level Tutorial for that level
- Subscribe() wires it up after all dependent services exist
- Locks TreeRotateService and CameraPeekService while a tutorial runs, unlocks on Init/Clear

Tutorial.cs — [NEW]
- Base class with Id, a virtual Description, and a WaitForSignalAsync helper for steps

TutorialContext.cs — [NEW]
- Carries Board, Click, Overlay, Layout, Signals, Rotate, and Peek into a running tutorial

GuidedMoveTutorial.cs — [NEW]
- Abstract move lesson: scans the board for a valid move via BoardRules.CanMove
- Restricts clicks to the source branch, highlights it, points the hand, waits for the lift
- Repeats highlight + point on the destination branch and waits for the flock to land

FirstMoveTutorial.cs — [NEW]
- Level-1 lesson; later reduced to a GuidedMoveTutorial subclass carrying only the copy text

SecondMoveTutorial.cs — [NEW]
- Level-2 GuidedMoveTutorial subclass with Id tutorial_second_move

RotateTutorial.cs — [NEW]
- Level-3 lesson: blocks every branch click, shows the swipe hand hint
- Waits until the player rotates the tree past a delta-angle threshold

TutorialOverlayUI.cs — [NEW]
- Overlay UI with Highlight/ClearHighlight, PointAt/StopPointing, ShowSwipeHint
- ShowDescription/HideDescription for the per-level caption

TutorialPointer.cs — [NEW]
- Spine hand pointer with a tap pulse and PlaySwipe() horizontal drag gesture
- Drag runs Hold/Drag/EndWait phases with configurable distance, duration, and ease

RendererSpotlight.cs — [NEW]
- Dims the screen and cuts a mask hole over a target using the two tutorial shaders

TutorialSpotlightDim.shader — [NEW]
TutorialSpotlightMask.shader — [NEW]

TutorialSetupTool.cs — [NEW]
- Editor menu that builds the TutorialOverlayUI prefab (Canvas + Spine Hand_tap pointer)
- Registers the prefab in UIPrefabsSO; Setup keeps an existing prefab, Rebuild overwrites with a confirm
- Reset Seen clears the data_tutorial PlayerPrefs key so every lesson shows again

BranchClickService.cs — [MOD]
- Added RestrictClicksTo(branch) and RestrictClicksTo(branches) plus ClearClickRestriction
- Click handler drops branches outside the allowed set while restricted

UIService.cs — [MOD]
- Added ShowOverlay<T> and HideOverlay<T> for a layer that sits above screens and popups

tutorial.md — [NEW]
- Design doc describing the level 1-3 tutorial flow

----------------------------------------------------------------------

2. Element Intro Popup

ElementIntroService.cs — [NEW]
- On level-ready, shows ElementIntroPopup once per config entry Id, tracked through storage
- Skips the entry when storage.HasSeen(entry.Id), marks it seen after showing

ElementIntroConfigSO.cs — [NEW]
- Config asset holding ElementIntroEntry[] with FindByLevel(level)

ElementIntroEntry.cs — [NEW]
- Fields Id, Level, Icon, Title, Description

ElementIntroData.cs — [NEW]

LocalElementIntroStorage.cs — [NEW]

ElementIntroPopup.cs — [NEW]
- Popup rendering the entry icon, title, and description

GlowRotator.cs — [NEW]
- Spins a glow graphic behind the popup icon

LevelRunner.cs — [MOD]
- Raises IntroCompleted after the level intro finishes (or immediately when none plays)

GameController.cs — [MOD]
- Subscribes to LevelRunner.IntroCompleted

DataService.cs — [MOD]
- Exposes ElementIntroStorage

GameEventService.cs — [MOD]
- Added the OnLevelReady callback

----------------------------------------------------------------------

3. Audio / SFX

AudioService.cs — [NEW]
- Pooled one-shot SFX via PlaySfx with a per-key cooldown, plus one looping source
- PlayLoop/StopLoop drive the bird-fly loop; respects the SFX-enabled setting
- Reacts to level win/lose, selection change, bush leaf burst, bird flight start/end

AudioKey.cs — [NEW]
- Enum of sound keys (Win, Lose, BranchSelect, BushBurst, EggBreak, BirdFlyLoop, ...)

AudioEntry.cs — [NEW]
- Key with volume/pitch and a clip list; Sequential or random GetClip()

AudioConfigSO.cs — [NEW]
- Master volume, pool size, cooldown ms, and the sound entry list

BirdsFlightStartedSignal.cs — [NEW]
BirdsFlightEndedSignal.cs — [NEW]
- Mark the start and end of a bird flight so the fly loop can start and stop

BirdMoveService.cs — [MOD]
- Publishes the flight start/end signals around a move

HiddenFeature.cs / IceFeature.cs / KeyFeature.cs / LockFeature.cs — [MOD]
- Play the egg-crack, lock, and key SFX on their interactions

BranchBreakService.cs — [MOD]
- Plays the branch-break SFX

ButtonClickSfx.cs — [MOD]
- Routes button clicks through AudioService

HapticType.cs — [NEW]

HiddenFeature.cs / IceFeature.cs / KeyFeature.cs / LockFeature.cs — [MOD]

ButtonClickSfx.cs — [MOD]

AndroidManifest.xml — [MOD]

5. Ice Obstacle

IceFeature.cs — [MOD]
- Shakes the ice block and plays the crack fx when a clear reduces it without shattering

  selectable immediately; Unlock stays a safe no-op on the later RemoveCondition pass
```
