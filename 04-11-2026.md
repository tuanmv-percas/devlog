- Replaced Size / BorderThickness with Frame (Rect) and PerimeterOffset; added PerimeterLane rect

- ToLocalPosition takes a free Vector2 position; added ToLocalPlane / ToPosition; removed coord/index helpers

BlockVisual.cs — [MOD]

- Removed Outline3D reference and jump-based movement

3. Ants and Road

AntSpawner.cs — [MOD]
- Removed the door-post bounce call when a row leaves the road
- Auto queue (level with no groups) now builds one round from the board via AntData.CollectFromBoard instead of repeating until the road is full
- Replaced single openRow / nextArm with a list of open rows: opening a group reserves a contiguous run of free columns, one row per column
- Added ArrivalTime, LeadAt, Fits, PickRow, OpenBlock so each arm fills reserved rows whose column passes its merge point as the row arrives; removed mergeReach
- Rows are picked before ants surface so waiting ants already show the row colour
- Scaled spacing to ant scale 0.9: laneSpacing 0.36, rowSpacing 0.75, lift 0.075, peekGap 0.69, armSpacing 0.69, climbLength 0.62, followGap 1.12, holeClearance 0.44
- Crawl caps speed at turnSpeed * d / (2 sin delta) so an ant can always turn onto its goal; an ant still walking after 4 s slides straight into its slot
- edgeOffset default 1.12; tooltip states the rail must move with laneSpacing

AntData.cs — [MOD]
- Added CollectFromBoard(board, into): one group per block colour with count equal to that colour's total block capacity, in board order

RoadSpawner.cs — [MOD]
- Removed PlayDoor, doorPulse and the LitMotion punch on the door posts

Ant.prefab — [MOD]
- Ant model scale 0.72 to 0.9

LevelManager.prefab — [MOD]
- Road radius 3 and halfStraight 3 (taller at same width), hole mouth 0.5 to 0.65, 41 road columns instead of 49
- Outer rail moved from 0.7 to 0.92 so the outer lane of bigger ants clears it; door posts follow
- Removed door pulse value
