# sand-trip

```
1. Box Element

BoxElement.cs — [MOD]
- Added FlyLid(duration): the lid stretches on launch, then flies in a parabola diagonally left and back (-x, +y of the box) while spinning and twisting, shrinks to 0 and hides; it flies in a frame detached from the box so a box boarding mid-flight no longer drags it
- Added HurryLid(duration), which speeds up a lid already in flight so it finishes within the given time
- Added PlayClear(duration): flash, lid drops back and closes, box squashes, pops, then spins and shrinks to 0 on Root only, so the fill label and VFX stay unscaled
- Added IsLidOn and LidFlight properties; LidTop now reads the cached closed-lid pose instead of live lid renderer bounds, so it stays valid while the lid is away
- Added CacheLidPoses, DetachLid, AttachLid, PoseLid, CloseLid and the LidPose struct to store and restore each lid's closed pose relative to Visual
- Added lid-flight and Clear tuning fields (m_LidFlyHeight, m_LidFlyApex, m_LidFlyDistance, m_LidFlyBack, m_LidFlySpin, m_LidFlyTwist, m_LidLaunchStretch, m_LidShrinkStart, m_ClearLidDrop, m_ClearLidTwist, m_ClearSquash, m_ClearPop, m_ClearSpin)
- Added m_LidPopVfx, tinted from the box colour mixed with white (m_LidPopWhiten) and played on lid pop and on Clear
- Added m_SandFill with SetFill(fill), ShowFill(), HideFill() and ClearSand(); Init resets the lid, sand and label for pooled boxes, Clean stops the lid tween, Clear tween and VFX

BoxFillLabel.cs — [NEW]
- Sand fill % label shown under the box on the train, following the box in world axes and kept upright toward the gameplay camera
- Show(fill) floors the value to a whole percent, pops in on first show and punches the scale each time it crosses a 10% step; Hide() hides it at once; IsShowing exposes the state

BoxSandFill.cs — [NEW]
- Sand block inside the box body driven by sand.fbx: at low fill its bottom stays on the inner floor (m_Floor) and it stretches up to its own height, then the whole block rises to the rim (m_FullTop) at 100%
- Smooths the surface toward the new fill with SmoothDamp (m_SmoothTime) and turns the renderer off below 0.1% fill
- Show(fill) and Clear() set or drop the fill; Renderer is exposed for tinting

Box.prefab — [MOD]
- Wired the lid pop VFX, BoxFillLabel and the BoxSandFill child with the sand mesh

box.fbx — [MOD]
- Added a closed underside to the lid mesh

----------------------------------------------------------------------

2. Station

StationView.cs — [MOD]
- Hop into the station now uses ArcMotion with climbFirst, so the box climbs to its slot height before sliding in instead of cutting diagonally through the box below
- Replaced per-box restack tweens with one shared _restackShift that holds for RestackDelay after a box boards, then eases down; further boardings during the wait or the slide add to the same shift, and LateUpdate places idle boxes from it
- Landing now squashes the box, stretches it back up as the lid pops off (PopLid), then settles; a box landing on top triggers RushLidBelow so the lid below leaves faster
- Lidless boxes take a shorter stack step (StepOf, eased toward LidlessStep while the lid flies) so the stack has no gaps; SlotPosition takes fractional steps
- PopLid calls StationService.MarkReady so the train can take the box from that point on

StationService.cs — [MOD]
- Added MarkReady(box) and a ready set; the bottom box only leaves for the train after it has landed, squashed and popped its lid, otherwise the passing slot goes on empty

StationConfigSO.cs — [MOD]
- Added LidPopStretch, LidPopDuration, LidSettleDuration, LidFlyDuration, LidRushDuration and LidlessStep
- Removed LandSquashVibrato; LandSquash default 0.15 -> 0.3, LandSquashDuration 0.25 -> 0.08 s

ArcMotion.cs — [MOD]
- Added a climbFirst option to Play: the offset along the arc axis closes faster (cubic) than the lateral offset, so the target reaches the destination height before moving in

----------------------------------------------------------------------

SandSuctionView.cs — [MOD]
- Fill % now follows BoxSandChangedSignal and is hidden on BoxLeftTrainSignal
- Fill % appears only once the box has landed on its car, after BoardHopDuration, instead of during the hop down
- HandleBoxClearing hides the %, plays BoxElement.PlayClear and fires a pooled BoxClearVfx firework at the box near the end of the Clear (m_ClearVfxAt = 0.85)

BurstVfx.cs — [NEW]
- One-shot particle burst placed at a world point, tinting the selected particle systems from a colour mixed with white; reusable once IsPlaying turns false

SandSuctionConfigSO.cs — [MOD]

BoxClearVfx.prefab — [NEW]

VfxConfetti.mat — [NEW]

[GameplayScope].prefab — [MOD]
```
