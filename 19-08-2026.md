# gecko-jam

```
1. Arrow Core / Hole Dive

Arrow.cs — [MOD]
- Added _holeDistance (arc-distance of the hole centre = dive mouth) and _holeDiveEndDistance (mouth + dive length), both cached in RebuildWaypointsAndDistances
- Added GeckoConfig accessors HoleDiveEnabled, HoleDiveLength, HoleDiveEndScale, HoleDivePitchDeg, HoleDiveDrop with headless fallbacks

Arrow.Func.cs — [MOD]
- Added ComputeHole(): walks the exit lane out from the head cell to the first off-grid cell and caches its centre distance as the dive mouth
- Added DiveLength() returning 0 when the dive is off, so the gecko vanishes at the hole centre with no dive travel
- AnimateMovement finishes the arrow once the tail passes _holeDiveEndDistance when the dive is on, and keeps the old off-screen CheckIfFullyExited path when it is off
- AnimateForward stops the claim frontier at the last in-grid cell instead of advancing _claimHead into off-grid cells
- AdvanceBoth now decides "committed to exiting" by the head crossing the grid edge when the dive is on, and by leaving the picture bounds when it is off
- Added ChainReverseBlocker(): a reversing arrow whose tail cell is held by a Waiting follower forces that follower to reverse, unwinding a same-lane convoy head-to-tail
- ChainReverseBlocker ignores Exiting owners, which are crossing and vacate on their own
- Fixed the deadlock where a front arrow in Backing could not retreat while the rear arrow in Waiting never yielded, because a Backing cell is neither Idle nor Blocked

----------------------------------------------------------------------

2. Arrow Visual

Arrow.Visual.cs — [MOD]
- Added HoleDiveProgress(distance) returning 0 before the hole mouth and ramping to 1 across HoleDiveLength
- Added ApplyHoleDive(pos, distance) converging a rendered point onto the hole centre with an optional downward sink, applied downstream of ApplyCrawlOffset in the render path only so grid claim, tiling and reveal timing stay untouched
- Wired ApplyHoleDive into UpdateLinePoints for head, tail and every per-cell body vertex
- Head now pitches over its local X axis by HoleDivePitchDeg and shrinks to HoleDiveEndScale as it enters the hole
- Tail shrinks with no pitch so it enters rear-first without rearing up at the end
- Limbs pull their lateral splay to zero and shrink with the same dive progress
- Replaced the Lerp(pos, mouth, te) dive with a monotonic converge: the along-lane (exit-direction) component sitting ahead of the mouth is dropped entirely and only the lateral crawl wobble is eased out
- Fixed the visible tail kick-back at the end of the dive, caused by the surviving along-lane offset d*(1-te) peaking around 0.26*L at ~40% in and then falling back against the direction of travel

----------------------------------------------------------------------

3. Camera

CameraScaleHandler.cs — [MOD]
- Added a GeckoConfigSO lazy accessor via ConfigService
- Camera fit now adds Config.holeBorderCells on every side of the grid so the exit holes stay framed, and reserves nothing when holeDiveEnabled is off

CameraZoomHandler.cs — [MOD]
- TriggerZoomInOnAppear now runs on every level instead of only large (CanZoom) grids
- AnimateZoomInOnAppearAsync sets the camera to levelStartZoomAppearScale on appear, then drives orthographicSize by its own loop instead of calling AnimateToAsync
- Added AppearScaleCurve(): ease-out quad up to a (1 + overshoot) peak at 55% of the animation, then smoothstep settle back to 1, computed in picture-scale space so the bounce is distance-independent
- Resting framing resolves to MinSize on CanZoom grids and ComfortSize on small grids, avoiding a one-frame jump when the animation releases
- Holds _isAnimatingHome for the whole appear (delay plus zoom) so LateUpdate cannot drift the camera

----------------------------------------------------------------------

4. Config / ScriptableObjects

GeckoConfigSO.cs — [MOD]
- Added Hole Dive group: holeDiveEnabled, holeDiveLength, holeDiveEndScale (0-1), holeDivePitchDeg, holeDiveDrop

GameplayConfigSO.cs — [MOD]
- Added holeBorderCells (default 1) reserving camera border cells for the exit holes
- Added levelStartZoomAppearScale (range 0.3-1, default 0.75), the picture scale the level appears at
- Added levelStartZoomOvershoot (range 0-0.3, default 0.08), the bounce past the resting size
- Reworded the levelStartZoomDuration tooltip to say "appear framing" instead of "comfort framing"

GeckoConfigSO.asset — [MOD]
- Set holeDiveEnabled 1, holeDiveLength 1, holeDiveEndScale 0, holeDivePitchDeg 80, holeDiveDrop 0

GameplayConfigSO.asset — [MOD]
- arrowMoveSpeed raised from 10 to 20
- Set holeBorderCells 1, levelStartZoomAppearScale 0.85, levelStartZoomOvershoot 0.03

----------------------------------------------------------------------

5. Docs

docs/Gameplay.md — [MOD]
```
