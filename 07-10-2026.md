1. View Layer

SlotViews.cs — [MOD]
- Added SetAvailableWidth(float) storing the world-space width the whole slot row must fit into; triggers an immediate Relayout when slots already exist
- Changed TryGetGridStep() to return centerColumn as a float instead of a rounded int, and to also output cellWidth
- Replaced WorldToCell() with a direct (transform.position.x - origin) / step computation so the fractional part of the column is kept
- Changed Relayout() to round the first column exactly once, from the container position, instead of rounding both the center and the half row length
- Added RowWidth(), Fits() and FitStepColumns() shrinking the column step between slots down to 1 until the row fits the available width
