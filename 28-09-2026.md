# bus-down

```
1. Elements

BlockPathCurve.cs — [NEW]
- New class BlockPathCurve: a polyline with rounded corners, pre-sampled by arc length
- Build(points, cornerRadius) cuts the end of the incoming leg and the start of the outgoing leg at each corner, then joins the two cuts with a quadratic Bezier using the corner point as control
- Evaluate(progress) returns the position at 0..1 mapped by arc length, so speed stays constant along the curve
- Direction(progress) returns the travel direction at 0..1
- Skips corner sampling when two legs are collinear (dot >= StraightDot 0.999)
- FindSample does a binary search over the cumulative distance list
- Constants SamplesPerCorner 10, MinSampleStep 0.0001, StraightDot 0.999

BlockElement.cs — [MOD]
- Added field _modelBaseRotation, captured from m_ModelRoot.localRotation in Awake
- Added method StepTilt(worldStep, weight): rotates the model around Vector3.Cross(Vector3.back, direction) by Config.StepTiltAngle * weight
- Replaced the per-cell Tween.Position loop in the exit animation with a single Tween.Custom driving ApplyCrawl(progress) over the built curve
- Added BuildCrawlCurve(path, board): fills _crawlPoints with the current position plus each cell center, builds _crawlCurve with Config.CrawlCornerRadius, returns Config.StepDuration * (points - 1), returns 0 when there is no cell to crawl
- Added ApplyCrawl(progress): sets transform.position from the curve and m_ModelRoot.localRotation from the curve tangent
- Added CrawlTiltWeight(progress): SmoothStep ramp so tilt rises from 0 at the start and falls back to 0 at the end, ramp width _crawlTiltRamp clamped to 0.05..0.4
- Added public method PlayTravelTilt(worldDirection, duration): tilts toward the direction, holds, then returns upright inside duration; used for free flight legs that do not follow cells
- Added public method ResetTilt(): stops _travelTiltTween and snaps m_ModelRoot back to _modelBaseRotation
- Added field _travelTiltTween, stopped in OnDestroy alongside the other tweens
- ResetToSlot now restores m_ModelRoot.localRotation to _modelBaseRotation

----------------------------------------------------------------------

2. Pathfinding

ExitPathFinder.cs — [MOD]
- Replaced the forward BFS from the start cell with FloodFromExit: seeds every walkable cell on row 0 with distance 0 and flood-fills the whole grid
- Replaced buffers _visited (bool[]) and _cameFrom (int[]) with a single _distance (int[]); renamed constant NoParent to Unreached
- EnsureBuffers now refills _distance with Unreached on every call instead of Array.Clear
- Added Walk(grid, start): descends from start to row 0 one distance step at a time, appends the exit step (y = -1), then reverses the path
- Added TryFirstStep: picks the neighbour of start with the lowest distance; returns false when start is boxed in
- Added TryNextStep: scans the 4 directions starting from the current heading, so a shortest path with fewer turns is preferred
- FindPath returns immediately with a single exit step when start.y == 0
- Walk clears the path instead of returning a partial one when no next step is found
- Removed method BuildPath

----------------------------------------------------------------------

3. Services

ReviveSweepService.cs — [MOD]
- MoveBlockAsync now captures the start position and calls block.PlayTravelTilt(target - start, duration) before starting the position tween
- Added block.ResetTilt() before slot.SetBlock(block) so the block lands upright in the slot

----------------------------------------------------------------------

4. Config / ScriptableObjects

BlockAnimConfig.cs — [MOD]
- Added field StepTiltAngle (default 14 degrees, 0 disables the tilt)
- Added field StepTiltDuration (default 0.06s), clamped against leg length so the crawl rhythm is not stretched
- Added field CrawlCornerRadius (default 0.5): share of the cell edge cut on each side of a corner, 0 keeps the grid-shaped polyline, 0.5 is the maximum round
```
