# bus-down

```
1. Difficulty Banner

LevelDifficulty.cs — [NEW]
- New enum LevelDifficulty with Normal, Hard, SuperHard

LevelDifficultyRules.cs — [NEW]
- Added FromLevel(level): levels divisible by 10 are SuperHard, divisible by 5 are Hard, everything else (and levels below 1) is Normal

DifficultyBannerView.cs — [NEW]
- New start-of-level banner with a diagonal tag strip, UFO icon and title image; sprite set, title position / scale and edge warning flag declared per difficulty
- Added PlayAsync(difficulty, ct) that swaps sprites and runs the in - hold - out sequence; returns false when no sprite set exists for the difficulty
- In: tag strip opens and slides, UFO flies in, title pops with a diagonal shine sweeping across tag and title
- Hold: UFO floats, title pulses, edge warning blinks, each with an even number of yoyo loops so they end at the start pose
- Out: UFO winds up and flies off along the strip angle, title shrinks, then the strip closes
- Super Hard shows red edge glow on both screen sides
- Added screen dim (m_Dim, alpha 0.35, fade-in 0.25s) under the banner, cleared when the banner exits
- Tag uses its own material (m_TagMaterial) with the flow effect; shine parameters for the tag are copied from m_ShineMaterial (CopyShineSettingsToTag)
- Added SyncFromAssets() so editing the material assets in Play mode updates the running banner in the Editor
- Tag close time reduced from 0.25s to 0.16s; dim and edge warning got a separate m_FadeOutDuration (0.25s) to keep their old fade timing

GameSessionController.cs — [MOD]
- Added m_DifficultyBannerPrefab; banner is skipped when empty or when the level is Normal
- Added PlayDifficultyBannerAsync(): locks Block taps, waits for the level intro, instantiates the banner under the controller, plays it, then destroys it and unlocks taps in finally
- Out-of-lives popup and tutorial now wait for the banner to finish

UIShine.shader — [NEW]
- New shader Percas/UI/Shine: diagonal shine band driven by _ShinePosition, _ShineSlope, _ShineLead, _ShineTrail, _ShineColor
- Added flow mode (_FlowDir, _FlowSpeed, _FlowPeriod, _FlowStrength, _FlowCenterMask, _FlowTime): both sides of the tag strip scroll outward along the arrow direction while the center stays still

UIEdgeGlow.shader — [NEW]
- New shader Percas/UI/EdgeGlow: glow on both screen edges fading toward the center

DifficultyBannerShine.mat — [NEW]
- Shine material for the banner title; later widened the shine (_ShineLead 80 -> 160, _ShineTrail 260 -> 700) and added flow parameters

DifficultyBannerTag.mat — [NEW]
- Tag strip material with flow enabled

DifficultyEdgeWarning.mat — [NEW]
- Edge glow material for the Super Hard warning

pfb_difficulty_banner.prefab — [NEW]
- Banner prefab with Canvas, CanvasGroup, dim layer, edge warning, tag / icon / title images and Hard / Super Hard sprite sets

Gameplay.unity — [MOD]
- Assigned pfb_difficulty_banner to GameSessionController

Art/UI/Difficulty — [NEW]
- Added HardTitle, SuperHardTitle, icon_hard, icon_super_hard, tag_hard, tag_super_hard sprites

Piece.prefab — [MOD]

Gameplay.unity — [MOD]

6. Editor Tools / Recorder

ScreenRecorder.cs — [NEW]
- Ported the MP4 recorder (H.264 / AAC via MediaEncoder) from Core, no Recorder package or ffmpeg needed
- Play mode records at a fixed frame rate through Time.captureFramerate, with audio from AudioRenderer synced per frame
- Scene view source records outside Play mode on real time; optional GIF export through ffmpeg
- Added shortcut Recorder/Toggle Recording; max video size 4096

RecordCapture.cs — [NEW]
- Finds the camera, renders it (with Overlay UI canvases) or the Scene view (no gizmos / grid) into a RenderTexture, names output files and shows Editor notifications

RecordFrame.cs — [NEW]
- Pending GPU readback plus how many times it is written to the video

RecordPlan.cs — [NEW]
- Validated video size and capture target

RecordSession.cs — [NEW]
- State of one recording session

RecorderSettings.cs — [NEW]
- Settings model: source (Game view / Camera / Scene view), size presets or custom size, fps 30, quality, audio, include UI, output folder Captures/Recordings, reveal after recording

RecorderSettingsPopup.cs — [NEW]
- IMGUI popup for source, size, fps, quality, folder and GIF; replaces the old Screenshot window

RecorderOverlay.cs — [NEW]
- Scene view overlay "Recorder" with record toggle and settings popup button

RecorderRunner.cs — [NEW]
- Runtime component that calls back at end of frame in Play mode, after Overlay UI is drawn; wrapped in UNITY_EDITOR so it stays out of builds
```
