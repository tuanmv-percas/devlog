# sand-trip

```
1. Gameplay Scripts

SandSuctionView.cs — [MOD]
- Set BoxFireworkVfx as the clear VFX in place of BoxClearVfx
- Fired the firework at the box centre captured before Clear instead of the box pivot
- Added m_ClearVfxLift to push the firework toward the camera so the train car does not hide it
- Added ClearVfxFollow list and LateUpdate step that moves each playing firework with its train slot along the track
- Added SlotOf, SlotPoint and LiftTowardCamera helpers; falls back to a static burst when the train is not bound

BoardShadowPlane.cs — [NEW]
- Publishes the board floor plane to global _PlanarShadowPlane for the Percas/PlanarShadow shader
- Publishes _PlanarShadowClip so shadows fade out above the board's top edge (m_TopMargin, m_FadeLength)
- Recomputes the board half-height on BoardView.Built

RendererTint.cs — [MOD]
- Switched property block from _BaseColor/_BaseMap to per-instance _TintColor and _Index
- Apply() now takes a texture array layer instead of a Texture

PairColors.cs — [MOD]
- Replaced Pick<T>() with LayerOf(pairId), returning the texture array layer (0–3, 4+ maps to 0, -1 when unpaired)

LockElement.cs — [MOD]
- Removed m_PairTextures list; lock picks its layer through PairColors.LayerOf

KeyFeature.cs — [MOD]
- Removed m_PairTextures list; key stores a texture array layer instead of a Texture and reuses it during the fly-to-lock tint

----------------------------------------------------------------------

2. UI Layer

LevelCompletedPopup.cs — [MOD]

SpineTransition.cs — [NEW]

CurveScaleTransition.cs — [NEW]
- ITransition that pops a target along an AnimationCurve (0.8, 1.1, 1.0)
- Added optional out step (fade duration, shrink to m_OutScale with InBack), off by default

HoldToPeekBoard.cs — [NEW]
- Fades the fail popup's CanvasGroup out on pointer down (0.15s) and back on release (0.12s) so the board shows through

4. Shaders / Materials

PlanarShadow.shader — [NEW]
- Flattens casters onto a ground plane along a fixed light direction and fills them with one colour
- Uses a stencil bit so overlapping shadows do not darken twice; fades out past _PlanarShadowClip

UnlitTextureArray.shader — [NEW]
- Samples one layer of a Texture2DArray times a tint, with _Index and _TintColor as per-instance properties for GPU instancing

PlanarShadow.mat, PlanarShadowTrack.mat — [NEW]
- Shadow materials for the board layer and the train/station rail plane

Box_Unlit.mat, Sand_Unlit.mat, Lock.mat, Key.mat — [MOD]
```
