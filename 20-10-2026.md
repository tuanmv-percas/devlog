# GeckoJam

```
1. Gecko Drop Shadow

3DResources/Shaders/GeckoShadow.shader — [NEW]
- Added Custom/GeckoShadow, a flat silhouette shader on render queue 2990 so it draws under every queue-3000 renderer
- Uses stencil so overlapping shadows stay at one tone; colour comes from the global _GeckoShadowColor

Scripts/GamePlay/ArrowPicture/GeckoShadow.cs — [NEW]
- Shared shadow helper: pushes shadow colour/offset from GeckoConfigSO to globals and builds per-texture materials without an MPB so unfaded head shadows can dynamic-batch

Scripts/GamePlay/ArrowPicture/GeckoShadowCaster.cs — [NEW]
- Component that re-draws a renderer's sprite as a shadow shifted by shadowOffset, attached at runtime to obstacles and board elements

Scripts/GamePlay/ArrowPicture/Arrow.Visual.cs, Arrow.cs, Arrow.Func.cs — [MOD]
- Body shadow is a child LineRenderer mirroring the body polyline and sharing the body MPB, so tiling and the intro reveal match
- Per-vertex shadow offset eases to 0 through the hole dive so the shadow sinks with the gecko

Scripts/GamePlay/ArrowPicture/ArrowHeadVisual.cs — [MOD]
- Re-draws the Spine head mesh as a shadow in OnMeshAndMaterialsUpdated, so blink, tongue, stun and dive pitch all cast

Scripts/GamePlay/ArrowPicture/ArrowPictureService.cs — [MOD]
- Added DrawShadows: tail and limb shadows are drawn instanced, one batch per part (16 colour sprites share one silhouette), 3 draws total

Scripts/GamePlay/ArrowPicture/SpriteShatter.cs — [MOD]
- Shatter pieces of the cloth element now carry a GeckoShadowCaster

Obstacle/Defuse, Hidden, KeyLock (Key + Lock) abilities; BoardElement/Bomb, Cloth abilities — [MOD]

# bus-down

```
1. Creative Tools

Scripts/SnakeFlow/Creative/HudToggleHotkey.cs — [NEW]
- Editor-only component, auto-spawned via RuntimeInitializeOnLoadMethod, that toggles HUD visibility with Space for creative capture
- Disables the Canvases of GameHUD and ResourcePanel (coin/lives bar) and hides the DevTool bubble; popups stay visible
- Hidden state is static, so it persists across next level and retry; re-applied in LateUpdate so a freshly built HUD is hidden before its first frame
- Clears the EventSystem selection before toggling so Space does not fire Submit on the last pressed button

Scripts/SnakeFlow/Creative/CreativeHandController.cs — [NEW]
- Editor-only controller that loads HandCursorCanvas through AssetDatabase on first enable, so the hand assets never enter a build
- Hand lives across scenes (DontDestroyOnLoad), sits at sorting order 32000 above all UI, and has raycasts disabled so it never blocks taps
- Hides the OS cursor while the hand is active, except when the DevTool screen is open
- Hand scale is clamped to 0.3–3 and kept static while the hand is off

Scripts/SnakeFlow/Creative/CreativeDevTools.cs — [NEW]
- Added a Creative tab in DevTool with a Show Hand toggle and a Hand Size slider

----------------------------------------------------------------------

2. ThirdParties / HandCursor

ThirdParties/HandCursor/ (HandCursor.cs, HandCursor.prefab, HandCursorCanvas.prefab, Press/Release anims, tutorial.png) — [NEW]
- Ported the HandCursor asset from BirdStory: follows the mouse, plays Press/Release on click, SetScale for resizing
- Deactivates itself outside UNITY_EDITOR
