# bus-down

```
1. Piece Movement

PieceGrid.cs — [MOD]
- Added SealBottomBandRow(rowFromPicture, gapWidth) which marks a whole row of the bottom band as Blocked and leaves a centred gap
- Added BottomBandRow(rowFromPicture) to convert a bottom-band offset into a picture row index
- Added WallRow property and _wallRow field, -1 when no row is sealed
- Widened the gap by one cell when its parity differs from the grid width, so an even-width row still gets a centred gap
- Added SlotFloorMark constant (byte 2) to tag cells covered by a parked Block model
- Added CollectCells(center, half, cells) to turn a world-space bounds into the list of grid cells it covers
- Added SetSlotFloorBlocked(cells, blocked) to block or open a measured cell set
- Replaced the single _padding field with _topPadding, _leftPadding and _rightPadding, and replaced the Padding property with TopPadding, LeftPadding and RightPadding
- Changed Rebuild signature from (pictureService, pictureView, bottomPadding) to take leftPadding and rightPadding as separate arguments

PieceMovementService.cs — [MOD]
- Added SealBottomWall(), called once in Bind right after Rebuild
- Added TryGetSlotTopMidRow, TryResolveSlotTopMidRow and TryMeasureSlotTopRow to measure the wall row midway between the row under the picture and the row nearest the top edge of the slots
- Skipped the seal when no slot exists yet, and when the measured row lands on the gate row
- Added TickRise, ApplyRiseHop and PlayRiseTransform for the new Rising state: a parabolic arc subtracted from z, with the box bursting into the character model at riseTransformAt
- Captured the static box z as the hop ground plane before UpdateTransform pushes the Piece onto the crawl plane
- Added RefreshSlotFloors, ApplySlotFloor, SameCells and MeasureBlockFootprint to re-measure each parked Block model footprint per frame and write it into the walkable grid
- Opened the previous footprint before blocking the new one, and released the surplus cells when the slot row shrinks
- Added MeasureSidePadding and MinSidePadding constant (2) to widen the left/right grid border to the outermost slot edges
- Added PlayStepFx, NextStride, PlayStepPrint and FacingAngle to emit step dust and footprints by distance travelled rather than by timer
- Measured travel after the position is clamped to the walkable cell, so a Piece held by a wall emits nothing
- Primed the first stride in full, once per Piece, so footprints appear immediately instead of after a full stepStride
- Added _stepFxBudget per frame and _colorService injected through the constructor
- Changed the PieceGrid.Rebuild call site to pass the measured left/right padding

PieceMovementConfig.cs — [MOD]
- Added bottomWallGapWidth (default 2)
- Changed enterSwirlTurns from 0.5 to 1, so a piece circles the beam axis once on its way up
- Added riseDuration (0.4), riseJumpHeight (1), riseTransformAt (0.4) and bodyFrontZOffset (0) for the stand-up state
- Moved the crawl plane from SnakeFrontZOffset to bodyFrontZOffset; SnakeFrontZOffset is unchanged and still used by SnakeView
- Added stepStride (2), stepMinSpeed (1.5), stepFxPerFrame (4), stepStrideJitter (0.15), stepPrintSideJitter (0.08), stepPrintAliveCount and stepPrintZOffset (-0.02)

PieceMoveAgent.cs — [MOD]
- Added riseRemaining, riseDuration, riseTransformed and riseBaseZ fields for the Rising state
- Added stepTravel, stepNextStride and stepPrimed fields for distance-accumulated step FX

PieceAvoidanceSimulator.cs — [MOD]
- Included agents in the Rising state in BuildBuckets, so a standing agent occupies space and crawling agents steer around it instead of passing through
- Left the solve loop running for Moving only, so a rising agent acts as a static obstacle and is never pushed

----------------------------------------------------------------------

2. Block Elements

BlockElement.cs — [MOD]
- Changed HideBeam to return the beam fade-out duration, and chained that duration as a delay ahead of the windup in PlayClearAsync so the pool dims on the slot floor before the ship moves
- Added an onLiftOff callback parameter to PlayClearAsync, fired when the lift tween starts; Destroy still runs at the end of the animation
- Added PunchBlock and _arrivePunchTween: the punch on each arrival now runs on m_Root instead of the label transform, so model and capacity number scale together
- Killed the punch tween before the three remaining writes to m_Root.localScale, and skipped the punch while IsSuperSnake
- Made TryGetModelBounds public and added the _clearing flag plus the IsRestingInSlot property
- Added _shadows, _shadowAlpha, _shadowAlphaFrom, _shadowAlphaTo and ApplyShadowAlpha for the rebuilt Block shadow
- Pinned both shadow alpha endpoints before building the flight arc and interpolated along the bow, so the shadow fades across the flight between two slots as well

BlockBeamVisual.cs — [MOD]
- Changed Hide to return the fade duration it takes
- Cleared the motes outright at the top of Hide instead of letting them finish their flight; they render from their own material and never read the mesh _Alpha

3. Pictures

PieceMoveVisual.cs — [MOD]
- Replaced SkinnedMeshRenderer and Animator with MeshRenderer, MeshFilter and a static Mesh driven by a vertex animation texture
- Replaced SpeedId and the MoveState string with the AnimPhaseId and OffsetId shader property ids
- Added m_Mesh, m_BodyMaterial, m_ShadowMaterial, m_ClipLength (0.633), _materials and _phase
- Changed Play signature from (material, colorIndex, popDuration, cadenceJitter) to take the shadow world offset instead of a material
- Added SetShadowVisible, ApplyMaterials(withShadow) and ApplyProperties(colorIndex, shadowOffset)
- Added m_RiseSquashHeight (0.08) and m_RiseSquashSpread (1.15); the unbox beat now stretches up from a flattened pose instead of scaling out from zero
- Used the local y of the MoveVisual node as the height axis, since that node is rotated -90 around x

PictureView.cs — [MOD]
- Added m_StepDustBurst and m_StepPrintBurst serialized fields
- Added WorldToColumn(world) to convert a world position into a picture column
- Added PlayStepDust(worldPosition) and PlayStepPrint(worldPosition, rotationDegrees, lifetime, ...)
- Added PieceShadowWorldOffset, read at runtime so the Piece shadow offset follows the per-level picture scale instead of being baked into the material

PieceUnboxBurst.cs — [MOD]

- Disabled the PieceUnboxBurst emission at the moment the box bursts open

Piece.cs — [MOD]

- Added SetMoveShadowVisible(visible)

4. Services

SlotsService.cs — [MOD]

5. View / Controllers

PieceWallView.cs — [NEW]
- New MonoBehaviour that fills the sealed wall row with pipe models, replacing the gizmo-only representation
- Added Build(grid, camera) and Clear()
- Added CollectRuns to gather contiguous wall-cell runs on the wall row, and BuildRun to cap the ends facing a gap with the flared end model and tile the rest with body segments
- Added ResolveOuterEdges to extend a run that touches the grid border out to the camera viewport edge, so the pipe row spans the full screen width
- Added TryMeasure to read Renderer.bounds off the model itself for pivot compensation and segment length, so swapping the model needs no manual numbers
- Added Place, Flush and ResolveScale; m_Thickness is the pipe diameter in cells and the scale factor is derived from the body model diameter
- Drew each model type with a single InstancedMeshRenderer, so the whole row costs two draw calls
- Added the Segment readonly struct holding mesh, material, localMatrix, scale and length
- Added serialized fields m_BodySegment, m_EndSegment, m_Material, m_Thickness and m_Offset
- Called Init on every Build because it captures localToWorld and LayoutService sets a different picture scale per level
- Used the Percas/UnlitTexture material with GPU Instancing enabled rather than the Standard material embedded in the FBX, since the scene has no Light

GameView.cs — [MOD]
- Added the m_PieceWall serialized field and the PieceWall property

GameController.cs — [MOD]
- Called PieceWall.Build with the piece grid and camera after PieceMovementService.Bind

8. Editor Tools

VertexAnimationBaker.cs — [NEW]
- New editor utility baking the Piece move clip into a vertex animation texture and a static mesh, 32 frames
- Added BakePieceMove, Bake, WriteClipLength, ResolveClip, WriteTexture, WriteMesh and WriteAsset
- Changed ResolveClip from (Transform moveVisual) to (string modelPath) and added PieceModelPath, sampling directly from character_anim.fbx and taking the clip from the model sub-asset
- Built the output mesh from scratch instead of via Instantiate, which inherited isReadable from a model with Read/Write disabled and returned an empty uv2; with an empty uv2 every vertex read column 0 of the texture and the model collapsed to a point
- Verified the baked uv2 has all 1064 elements in order with isReadable true, and the baked result matches the previous version texel for texel
```
