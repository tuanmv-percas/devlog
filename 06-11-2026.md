# ant-hustle

```
1. Block Carry / Tow

BlockVisual.cs — [MOD]
- Added a Hook phase between Shift and Forward (CarryPhase: Lift, Reverse, Shift, Hook, Forward)
- After the reverse, one attached ant becomes the lead and tows the block: the block centre slides straight toward the exit while the off-centre pull turns the whole group until the lead sits at the leading edge
- Added BeginTow(), Tow() and EnterShift(); tow has no momentum (critically damped sway) and the pull starts during the shift pause so the group turns before it slides
- Speed now rises on one smoothstep curve through Hook and Forward (ForwardDistance / RampDistance made static with a ramp parameter)
- The block no longer turns while backing out
- Added TowStyle enum (MoveWhileTurning, TurnThenMove): turn while moving and finish after hookTurnDistance (3), or turn in place over hookTurnTime (0.45 s) before sliding off
- Replaced carryTurnStart and hookTurn with towStyle, hookTurnDistance and hookTurnTime; added hookPull (0.45)

AntSpawner.cs — [MOD]
- Added PickLeader(): the lead is the attached ant needing the smallest turn above leaderMinTurn (10 degrees); ants behind the block are only picked when nothing else is left
- CarryPath() now returns the exit direction used to pick the lead
- carryTurnRadius changed from 0.25 to 0.3
- Added LifterStrain (0.7): during the carry each attached ant gets Ant.SetStrain(0.7), the lead gets SetStrain(1, puller: true)

----------------------------------------------------------------------

2. Ant Animation

Ant.cs — [MOD]
- Added SetStrain(amount, puller): ants on a carried block keep stepping even when the block is still (strainStepRate 3.5), with strainBlend to ease in/out
- Run clip plays backward when an ant is dragged toward its tail; gait flips over reverseTime (0.12 s)
- The puller (lead ant) always steps backward while straining and tugs its body back each half stride (strainSurge 0.05)
- Added body swing around the bite point (gripReach 0.38): each ant leans its body toward where the block is going, scaled by grip speed (swingFullSpeed), capped at swingMax (60 degrees), driven by a spring (swingFrequency 2.5, swingDamping 0.6)
- Model local position and rotation cached in Awake so PoseModel() can apply the swing

----------------------------------------------------------------------

3. Ant Approach to Attach Point

AntSpawner.cs — [MOD]
- Added ApproachAim: walking ants aim ahead of their attach point, swinging wide or orbiting the block when the spot is on its side or far side, so they arrive already facing the block centre
- Final settle follows a cubic Bezier arc (SettleArc / SettlePose) tangent to the crawl direction at the start and to the inward direction at the end, walked by arc length (SettleSamples = 16) and easing as 1 - (1 - t)^3 from the current speed to rest
- Removed the Hermite slide with a separate turn in place at the end
- Settle starts early within SettleReach (0.6) when the ant is in front of the spot (SettleCone ~45 degrees), or immediately if an ant is stuck crawling too long
- Added Front(), Inward() and Bezier() helpers

----------------------------------------------------------------------

4. Ant Steering Around Docked Blocks

AntSpawner.cs — [MOD]
- Added SteerAround(): look-ahead that retargets to a corner of an inflated block box when the straight line to the aim cuts through a docked block, so ants curve around it from a distance
- Added AvoidBlocks(): bends the desired heading tangent to a docked block within 2 x BlockClearance, with an outward push when closer; fades out near the target block's attach spot
- Added BlockDistance(), SegmentEnters() and Clip() (Liang–Barsky segment vs box test), BlockHalf(), BlockEdge (0.42) and BlockClearance (0.25)
- Added NearOtherBlock(): pulls the approach aim back when it falls inside a neighbouring docked block's clearance
- Turn radius is now measured against the current aim point when it is closer than the goal, so ants no longer loop around a corner they are steering past
- A corner the ant has reached within 2 x BlockClearance is treated as passed, which stops ants spinning in place at the corner

----------------------------------------------------------------------

5. Hidden Obstacle

HiddenObstacle.cs — [MOD]
- Hidden block now probes its own exit lane on every board recalculation and reveals as soon as nothing blocks it, including on the level's first calculation
- Removed the old rule of waiting for an adjacent block to leave (leftover from the grid board)

Board.cs — [MOD]
- Removed Board.AreNeighbors, which only HiddenObstacle used

BoardChange.cs — [MOD]
- Dropped the Hidden reference from the doc comment on BoardChange.Left (comment-only change)

----------------------------------------------------------------------

6. Prefab Updates

Block.prefab — [MOD]
- Serialized towStyle (1 = TurnThenMove), hookPull 0.45, hookTurnDistance 3, hookTurnTime 0.45; removed carryTurnStart

LevelManager.prefab — [MOD]
- carryTurnRadius 0.25 -> 0.3, added leaderMinTurn 10
- introStyle switched from None to Appear
```
