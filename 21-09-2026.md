# mahjong-craze

```
1. Level Editor

FloorToolbar.cs — [MOD]
- Added HandleKeyboardDelete() so Delete/Backspace over the SceneView deletes the selected floor
- Swallow SoftDelete/Delete command events so Unity does not also delete the selected GameObject
- Skip deletion while editing a text field (EditorGUIUtility.editingTextField)
- Added DeleteFloor(int) removing every tile, printer and concrete tile on the floor, with a confirm dialog for a non-empty floor
- Added ShiftFloorsDownAbove() to shift floors above the removed one down by one so indices stay contiguous
- Clear Selection.activeGameObject before respawn to avoid a dangling reference

LayoutGenerator.cs — [NEW]
- Added editor-only procedural geometry generator (Floor/Position only, TileType left empty)
- Built floor 0 from a base shape: Rectangle, Diamond, Ellipse or Cross
- Stacked upper floors only on supported cells via SupportedCandidates using OcclusionGraph.CoverOffsets (FullQuad / AtLeastOne)
- Added density + symmetry (None/Horizontal/Both) filtering with orbit-based decisions for exact symmetry
- Made output reproducible by Seed and forced total tile count divisible by 3

TilePanel.cs — [MOD]
- Added DrawLayoutGenerator() rendering a "Generate Layout" section at the bottom of the Tile panel
- Exposed Shape/Width/Height/Floors/Density/Symmetry/Support/Seed controls plus a random-seed dice button
- Added preview tile count recomputed only when params change
- Added Generate and Regenerate (seed++) buttons calling DoGenerateLayout
- DoGenerateLayout replaces the whole board (clears tiles/printers/concrete) and respawns via FloorToolbar.RebuildSpawner

LevelEditorStyleDatabase.asset.asset — [MOD]
- Added style database entries for the level editor

----------------------------------------------------------------------

2. Levels / Generation

OcclusionGraph.cs — [MOD]
- Added public CoverOffsets(int lowerFloor) returning the parity-based offset set, so the layout generator reuses the runtime occlusion parity rule as a single source of truth
```
