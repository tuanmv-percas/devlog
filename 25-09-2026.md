```
1. Services

ReviveSweepService.cs — [NEW]
- Added revive sweep flow: a block leaves its slot, flies straight to the cell with the most same-colour pieces in its 3x3 neighbourhood, pulls the cluster in, then moves to the next densest cluster until full or the picture runs out of that colour
- Flies over everything with no pathfinding
- CanSweep() / FindTargetSlot() pick the block with the highest AbsorbableCount (remaining capacity clamped by pieces left of that colour), read-only so the popup can ask before charging coins
- SweepAsync() removes the block from the slot and calls LockInput so the normal refill pass skips it; block full clears in place and raises BlockCleared with the world position, block still hungry flies back and NotifyBlockArrived resumes the refill
- Returns the block to its slot from a finally so leaving the scene mid-flight cannot strand it over the picture
- AbsorbPieceAsync detaches each piece, calls PictureService.MarkEaten, OpenGridCell, ReachablePieceService.TakePiece and ReduceCapacity, then tweens the piece onto the block

ReviveSweepConfig.cs — [NEW]
- New plain config class built with new in the installer, no Editor asset
- Fields sweepRadius, travelSpeed, minTravelDuration, maxTravelDuration, absorbDuration, absorbStagger, stopDelay, hoverZMargin

BoardService.cs — [MOD]
- Replaced HasBlockWithExit() with HasDispatchableBlock(int freeSlotCount)
- Both conditions "has an exit" and "free slots fit this block type" now have to hold on one block; a paired sticky block needs two free slots since the pair travels in one go

ReachablePieceService.cs — [MOD]
- Added TakePiece(Piece) that removes a piece from the index leaving its cell empty and unscanned, for picking a piece straight off the picture without going through ConsumeLayered
- Deliberately skips the scanned mark and flood so a hole in a sealed region is not treated as a way out

----------------------------------------------------------------------

2. Controllers

GameController.cs — [MOD]
- CanDispatchBlock() now delegates to BoardService.HasDispatchableBlock(FreeSlotCount) instead of combining HasBlockWithExit and HasOnlyStickyBlocks itself
- Added _reviveSweepService field, resolved from ServiceLocator, and Bind(m_PictureView, m_SlotViews) after the board is built

GameSessionController.cs — [MOD]
- ReviveAsync now selects ReviveSweepService.FindTargetSlot and awaits SweepAsync instead of SnakeService.FindSuperSnakeTargetSlot / ActivateSuperSnake
- Subscribed and unsubscribed ReviveSweepService.BlockCleared
- Added HandleSweepBlockCleared: plays a LightImpact haptic and a pooled burst through the same SpawnFx/ReturnFx path as the other revive effects, so a block that dies over the picture still gets the burst SlotView.PlayClearVfx cannot cover
- Added serialized fields m_SweepClearPrefab and m_SweepClearDuration

----------------------------------------------------------------------

3. UI Layer

FailedLevelPopup.cs — [MOD]
- Continue now checks ReviveSweepService.CanSweep() before charging coins instead of SnakeService.CanActivateSuperSnakeAuto()

----------------------------------------------------------------------

4. Prefab Updates

clear.prefab — [NEW]
- Lifted the clear VFX child out of SlotView.prefab into a standalone effect prefab under Assets/Prefabs/Effects, so slot clear and sweep clear render the same effect from one asset

SlotView.prefab — [MOD]
- Removed the inline clear VFX child and now nests clear.prefab

----------------------------------------------------------------------

5. Scene / Installer

GameplayInstaller.cs — [MOD]
- Registered ReviveSweepService in the service type list and instantiated it with picture, ReachablePieceService, PieceMovementService, slots, dispatch and a new ReviveSweepConfig

Gameplay.unity — [MOD]
- Set m_SweepClearPrefab to the clear effect and m_SweepClearDuration to 0.6 on GameSessionController
```
