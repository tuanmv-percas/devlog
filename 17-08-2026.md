# gecko-jam

```
1. Arrow / Gameplay

Arrow.cs — [MOD]
- Added _isWaiting state: arrow holds position mid-exit when a moving arrow occupies the exit lane ahead, distinct from _isReversing
- Reset _isWaiting in the arrow reset path
- Split TryExit into three exit-lane cases: stationary blocker reverses, moving arrow ahead defers confirm and waits, clear lane confirms and exits
- Deferred OnArrowConfirmedMoving when a moving arrow is ahead so a wait that ends in reversal never decrements a bomb step

Arrow.Func.cs — [MOD]
- Added waiting branch in AnimateMovement: arrow slides up behind a moving blocker, stops at arrowWaitGap, then holds
- Advanced head and tail in lockstep to the stop point so the body length stays intact
- Added AdvanceExit() holding the original forward-exit step (release tail cells, reverse on stationary blocker)
- Added UpdateWaitState(): resume when lane clears, reverse if a stationary blocker appears, keep holding while a moving arrow is still ahead
- Added TryGetExitBlocker(): returns nearest exit-lane blocker distance and whether it is stationary

GameplayConfigSO.cs — [MOD]
- Added arrowWaitGap field (default 0.1), the world-unit gap the head keeps behind a moving arrow it waits behind
```
