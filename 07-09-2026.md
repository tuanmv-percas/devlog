# bird-story

```
1. Bird Shaders & Outline

Bird.shader — [MOD]
- Reverted Bird shader to plain unlit
- Removed all in-shader outline logic (96 lines cut)

BirdOutlineMask.shader — [NEW]
- Stencil mask shader, queue Transparent+400, ColorMask 0, ZTest Always
- Marks the selected-bird silhouette into the stencil buffer

BirdOutline.shader — [NEW]
- Inverted-hull rim shader, queue Overlay, ZTest Always
- Draws the rim only where stencil != mask ref, never fills the body

BirdOutline.mat — [NEW]
- Overlay outline material
- Thickened the outline width (2 values changed)

BirdOutlineMask.mat — [NEW]
- Stencil mask material

BirdSkins/BirdSkin_0..11.mat — [MOD]
- Retargeted BirdSkin_0..7 _MainTex from Old to New textures
```
