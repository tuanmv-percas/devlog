# color-sand-block

```
1. Ice Machine Obstacle

IceMachineData.cs — [NEW]
- Added area element data IceMachineData (IAreaElementData, IDataClonable) with fields Cell, Direction (default Right) and IceLength (default 3)
- Added PlayedLength (IceLength clamped to at least 1), Step / StepOf(Direction) and IsHorizontal helpers
- AreaCell / AreaExtent cover the machine cell plus the ice strip along its facing; EditorBadge shows the ice length

IceMachineModel.cs — [NEW]
- Added model with IceLength, CurrentLength, IsGone and SolidCells (remaining ice cells + the machine cell)
- Break() removes one ice cell and reports whether a cell was removed

IceMachineElement.cs — [NEW]
- Added IceMachineElement : AreaElementBase<IceMachineModel, IceMachineData> with DefinitionId "ice-machine"
- Subscribes to BlockCompletedSignal; each completed block shortens the blocker collider by one cell at once
- Queues the pull animation one cell at a time (shake, slide, burst at the mouth) through _pending / PlayNext()
- Machine scales away after the last ice cell (Vanish / OnVanished)
- FitBlocker() resizes the BoxCollider2D blocker to the remaining solid cells; ShowIce() scales the ice bar

----------------------------------------------------------------------

2. Level Editor

IceMachineArt.cs — [NEW]
- Added IAreaKindArt that draws the machine cell, the ice strip, a facing arrow and the ice length on the level board
- Draws a red warning outline when the area is invalid

IceMachineRule.cs — [NEW]
- Added ILevelRule that reports an ice length below 1 and any block, wall or hole under the ice strip

ObstacleKinds.cs — [MOD]
- Added the Ice Machine display name to the obstacle kinds export

IceMachineSetup.cs — [NEW]
- Added menu Tools > Color Sand Block > Set Up Ice Machine
- Builds the placeholder prefab from cubes (one unit per cell, facing +X), two solid materials on the board's unlit shader, and the ice-machine element definition

ice-machine.png — [NEW]
- Added 128 px level editor icon in the FeatureIcons style (steel machine with the ice bar running into its mouth)
```

```
4. Stack Obstacle

StackData.cs — [NEW]
- Added StackData : BoardElementData with a pose and a list of StackEntry
- StackEntry holds ColorIndex, Length, CapacityOverride, Obstacles and Turn (heading relative to the stack, 0 = straight out); ToBlock() builds the BlockData
- GetEntryPose / EntryFootprint place a block in front of the mouth with its rear edge one Gap from the stack
- CollectFootprints adds every entry's spot

StackElement.cs — [NEW]
- Added StackElement : BoardElement<StackData>, IBlocker, IPoolable
- Pushes the first block at level start, keeps one block out at a time and pushes the next when that one leaves the board
- Waits and retries on each block exit while something still covers the next spot (IsTaken)
- Leaves the board after the last block and shrinks away once that block has slid out (Vanish)
- New blocks slide out of the tunnel and cannot be tapped until they land (PlaySpawn)
- PlayHitReaction bounces the stack when a block bumps into it; countLabel shows Remaining

BoardElement.cs — [MOD]
- Added virtual BoardElementData.CollectFootprints so the board frame wraps every entry's spot

BoardElementSpawner.cs — [MOD]
- Added SpawnLive(BoardElementData) to place elements mid-level
- Extracted SpawnElement(data, provider, layout) shared by level start and live spawn

AntData.cs — [MOD]
```
