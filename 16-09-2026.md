# bird-story

```
1. Gameplay / Features

HiddenFeature.cs — [MOD]
- Added Awake() caching the cover model's original parent and local pose (_modelHome, _modelHomePos, _modelHomeRot, _modelHomeScale)
- Added DetachFallingModel() reparenting m_ModelRoot to the tree anchor with worldPositionStays so egg-shell fragments fall in place after the bird is lifted
- Added ReattachFallingModel() restoring m_ModelRoot to its original parent and pose before the feature returns to the pool
- Added ResolveDetachAnchor() returning the branch's parent transform, or null when the bird has no branch
- Split RevealAnimationDuration into BirdRevealDuration and ShatterFallDuration
- Changed PlayFxThenReleaseAsync() to Unlock the bird right after BirdRevealDuration, then wait the remaining ShatterFallDuration before HideModel, so the bird is clickable before the shell finishes falling
- Called ReattachFallingModel() from OnRelease, ResetVisual and HideModel

KeyFeature.cs — [MOD]
- Added serialized fields m_MaterialLibrary (KeyLockMaterialLibrarySO) and m_BaseMaterial
- Added Awake() calling GatherTintRenderers()
- Added GatherTintRenderers() collecting child Renderers whose sharedMaterial equals m_BaseMaterial into _tintRenderers
- Added ApplyColorMaterial() setting those renderers to m_MaterialLibrary.FindKey(PairId), with an ElementLog.Warning when the pair id is missing
- Called ApplyColorMaterial() from Init()

LockFeature.cs — [MOD]
- Added serialized fields m_MaterialLibrary and m_BaseMaterial plus _tintRenderers
- Added GatherTintRenderers() (invoked from the existing cache pass) and ApplyColorMaterial() using m_MaterialLibrary.FindLock(PairId)
- Called ApplyColorMaterial() from Init()

BushFeature.cs — [MOD]
- Added serialized fields m_ColorSprite (SpriteRenderer) and m_SpriteLibrary (ColorSpriteLibrarySO)
- Added m_CheckSign and m_WoodSign transforms plus celebration tuning fields (m_CheckPopDuration, m_CheckPopEase, m_CheckPopSpin, m_CheckHold, m_SignScaleUp, m_SignScaleUpDuration, m_SignScaleUpEase, m_SignVanishDuration, m_SignVanishEase)
- Added ApplyColorSprite() setting m_ColorSprite.sprite from FindSprite(FeatureModel.ColorId), replacing flower material tinting
- Added FindSprite(colorId) returning m_SpriteLibrary.Find with a warning when the id is missing
- Added ResetCelebration() restoring check-sign and wood-sign base scale/rotation and killing the _celebration sequence
- Added a _celebration Sequence that stamps the check sign, scales the woodsign up then down to zero, then opens the bush covers
```
