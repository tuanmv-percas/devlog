# bird-story

```
1. Bush Feature

BushFeature.cs — [MOD]
- Subscribed to LevelIntroStartedSignal so bushes and the flower stay hidden (localScale 0) until the level intro beat, then grow in
- Added GrowInCovers() to grow the whole bush cluster staggered, then enter the idle sway
- Added GrowInColor() and GetFlowerGrowDelay() so the flower grows after the last bush finishes, then starts its pulse
- Added serialized field m_FlowerGrowDelay for the extra beat before the flower grows
- Removed PublishBirdRevealed() and the BirdRevealedSignal publish on reveal; bird reveal now only scatters leaves, no feather burst

BushAnimation.cs — [NEW]
- New per-bush tween driver: PlayGrow grows the bush in, PlayIdle sways it, with Cancel/ResetPose/Stop pose control

BirdElement.cs — [MOD]
- Added RevealFromCover(delay, duration, ease, onPop) to pop the bird skin from scale 0 to base scale with a bounce when it emerges from a bush
- Cached _skinBaseScale at build and kill _skinPop on recycle so a recycled bird never keeps a shrunk skin

----------------------------------------------------------------------

2. Hidden (Egg) Feature

HiddenFeature.cs — [MOD]
- Wired HiddenAnimation for the covering-egg idle and HiddenShatterAnimation for the reveal shatter
- Passed noPopCount so the nest (bottom fragment) drops straight down instead of bursting outward
- Hooked the bush + hidden intro so the egg waits for the level intro beat before appearing

HiddenAnimation.cs — [NEW]
- New tween driver for the covering egg: PlayIdle hovers up, punch-rotates (wiggle), and lowers back in a loop; ResetPose/Stop/Cancel control the pose

HiddenShatterAnimation.cs — [NEW]
- New shatter driver: each shell fragment bursts outward from the egg center, then falls below the screen while tumbling, staggered; runs in local-space so fragments rotate with the tree
- Changed the burst so shells fan outward by direction from center (BurstPortion, BurstUpBias) instead of a straight pop-up
- Added noPopCount parameter so the nest fragment falls straight without bursting

----------------------------------------------------------------------

3. Lock & Key Feature

LockFeature.cs — [MOD]
- Added the cage intro: cage-top parts spawn hidden above the lock and drop to snap over the bird on LevelIntroStartedSignal, with appear / overshoot / drop / land-squash tuning fields
- Detached the model to its slot during fly-in so the cage stays over the lock while the bird flies in, then re-attached it after landing
- Added the cage shatter on unlock: split out m_CageBottom, added shatter out-force / up-force / burst / fall / spin fields, cache per-piece pose via CachePieces
- Dropped the bird skin to perch at the start of the shatter (parallel) instead of after it, and removed the old punch-scale bounce

KeyFeature.cs — [MOD]
- Drove the key visual through the new KeyAnimation for the idle and fly-into-lock beats

KeyAnimation.cs — [NEW]
- New key tween driver: PlayIdle spins and bobs the key above the bird; settle/unlock one-shot beats return to base pose then shrink away with the lock

----------------------------------------------------------------------

4. Level Intro

LevelIntroService.cs — [MOD]
- Emitted LevelIntroStartedSignal so features grow in on the intro beat
- Added immediate intro modes: IntroSpinImmediate / IntroPitchImmediate set the tree and camera straight to the rest pose on frame one; kept pitch running concurrent with spin when immediate
- Guarded duration merging so a 0-length immediate leg is not stretched to match the other leg

RotateConfigSO.cs — [MOD]
- Added IntroSpinImmediate and IntroPitchImmediate config toggles to skip the intro spin/pitch ramp

GameContext.cs — [MOD]
- Passed scope.Signals into the feature wiring so features can subscribe to intro signals

----------------------------------------------------------------------

5. Tree Layout & Branch Break

LayoutConfigSO.cs — [MOD]
- Added TierTwistFromLevel (default 11): levels below it lay every tier at the same angle, no per-tier twist

BoardService.cs — [MOD]
- Took level in Init and passed applyTwist (level >= TierTwistFromLevel) into tier building

TierView.cs — [MOD]
- Added an applyTwist flag: off = all tiers place branches at the same angle, on = each tier twists by tier index

LevelSceneInstaller.cs — [MOD]
- Passed the level number into BoardService.Init

BranchElement.cs — [MOD]
- Kept the breaking branch parented under its tier instead of detaching to world, so both halves rotate with the tree while falling

BranchBreakService.cs — [MOD]
- Reworked the break tween to local-space (DOLocalMove / DOLocalRotate with LocalAxisAdd) and added ToLocalVector() to convert world offsets to local, so falling halves follow the tree's rotation

----------------------------------------------------------------------

6. VFX

VfxService.cs — [MOD]
- Prewarmed a leaf-VFX pool from VfxConfig.LeafVfx and subscribed to BushLeafBurstSignal to scatter a leaf cluster where a bush dissolves, parented under the tree
- Extracted BurstFeathers() and reused it for landing and reveal; subscribed to BirdRevealedSignal to burst feathers on reveal (later disabled from the bush side)

VfxConfigSO.cs — [MOD]
- Added LeafVfx, LeafPrewarm, LeafOffset, LeafEuler fields for the bush-dissolve leaf effect

----------------------------------------------------------------------

BirdRevealedSignal.cs — [NEW]

LevelIntroStartedSignal.cs — [NEW]
```
