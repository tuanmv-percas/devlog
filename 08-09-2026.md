# bird-story

```
1. Tree / Trunk

TreeView.cs — [MOD]
- Replaced SetTrunkRange(localBottom, localTop) with FitTrunkSpan(localBottom, localTop) that scales the trunk model uniformly from its mesh bounds
- Removed serialized m_TrunkUnitHeight; added m_BranchInset field and cached _trunkCollider
- Added SnapBranchesToTrunk() raycasting horizontally into the trunk collider to seat each branch base on the curved trunk surface
- Added GetTrunkCollider() building a runtime MeshCollider from the trunk MeshFilter when the scene has none
- Added GetTrunkReach() deriving the ray start distance from mesh bounds center offset plus extents
- Took branch outward direction from localRotation*forward instead of localPosition so repeated snaps do not invert
- Added back-face rejection in SnapBranch (skip when hit.normal points along the ray) to stop branches flipping to the trunk back side on re-snap
- Added editor-only SetTierBand and OnDrawGizmos drawing clearance bands, min/max tier stacks, and per-tier spacing rings

LayoutService.cs — [MOD]
- Call treeView.SnapBranchesToTrunk() after the trunk reaches final scale and position
- Switched the trunk fit call from SetTrunkBottom to FitTrunkSpan(localBottom, localTop)
- Replaced GetTreeBottomY / GetBottomClearance / GetTreeHeight with MeasureTierBand + GetTierBaseY, centering the tier stack inside a clearance-bounded band
- Added ShrinkFitAreaByNearDepth(nearDepth) and _bandTopY / _bandBottomY tracking

BoardService.cs — [MOD]
- Call _view.SnapBranchesToTrunk() before measuring board radius
- Passed _layout.BranchHeightJitter into TierView.Init

----------------------------------------------------------------------

2. Tier / Branch Layout

TierView.cs — [MOD]
- Added Init overload taking heightJitter and SetTierHeight(tierHeight) that re-places every branch Y from stored per-branch factors
- Added _heightFactors list capturing Random.Range(-1,1) per branch on Add so tier-height changes do not reshuffle
- Added GetHeightOffset(index) computing factor * jitter * tierHeight
- Made RemoveBranch remove the matching _heightFactors entry by index

LayoutConfigSO.cs — [MOD]
- Replaced ResidualSlackBelow with TopClearanceRatio / BottomClearanceRatio for the tier band
- Added BranchHeightJitter (Range 0–0.4, default 0.12)

BranchElement.cs — [MOD]
- Added m_Visuals array and RandomizeVisual() enabling one random visual variant on placement

----------------------------------------------------------------------

3. Birds

BirdElement.cs — [MOD]
- Added AlignFootToPerch(root) offsetting the skin so BirdSkin.Foot sits at the perch root, letting birds of any height perch flush
- Added _skinBase capture in Awake, SetSkinOffset(offset), DropSkinToPerch(duration, ease) with a DOTween fly-then-idle drop, and GetSkinBounds()
- Reset skin local position on despawn and on kill so a re-used instance does not stand offset

BirdSkin.cs — [MOD]
- Added serialized m_Foot Transform and Foot property marking the model foot point
- Added GetBounds() encapsulating all renderer bounds in world space

----------------------------------------------------------------------

4. Features (Lock / Bush)

LockFeature.cs — [MOD]
- Added m_BirdPosition, m_BirdShow, m_BirdShowHeadroom, m_DropDuration, m_DropEase serialized fields plus cached _birdShowScale / _birdShowRenderers
- Added OnPostInit → LiftBird() moving the caged bird skin to its in-cage stand and FitBirdShow() scaling the cage Y to cover the bird plus headroom
- Called bird.DropSkinToPerch(m_DropDuration, m_DropEase) on unlock so the freed bird drops to its slot

BushFeature.cs — [MOD]
- Replaced m_ColorRenderer + MaterialPropertyBlock tinting with m_ColorModel + ColorMaterialLibrarySO material assignment
- Assign sharedMaterial from m_MaterialLibrary.Find(ColorId) across all child renderers instead of setting a shader _Color property
- Changed m_ColorOffset from Vector3 to Vector2, keeping model depth from the prefab

ColorMaterialEntry.cs — [NEW]
- New [Serializable] entry pairing ColorId with a Material

ColorMaterialLibrary.cs — [NEW]
- New ColorMaterialLibrarySO with an Entries list and Find(colorId) lookup

----------------------------------------------------------------------

5. Camera Peek

CameraPeekService.cs — [NEW]
- New service rotating the camera around a horizontal axis through the aim point on vertical drag, easing back to the scene pose on release
- Init(gameView) / ResetPose() / Tick(deltaTime) API driven by RotateConfig (MaxPeekAngle, PeekDragDegrees, PeekReturnDuration)

RotateConfigSO.cs — [MOD]
- Added MaxPeekAngle, PeekDragDegrees, PeekReturnDuration fields under a "Ngó dọc" header

GameContext.cs — [MOD]
- Constructed CameraPeekService, registered it in ServiceLocator, and passed it to LevelReleaseService
- Constructed BranchClickService(scope) without the move / escape services

LevelRunner.cs — [MOD]
- Resolve CameraPeekService, call ResetPose() before the layout measure, then Tick(deltaTime)

LevelSceneInstaller.cs — [MOD]
- Resolve CameraPeekService and call Init(_gameView) after layout

DragInputView.cs — [MOD]
- Changed OnDragBegin / OnDragDelta / OnDragEnd from Action properties to events so multiple services can listen

----------------------------------------------------------------------

6. Branch Click
```
