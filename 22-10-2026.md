# sand-trip

```
Branches: feature/board/board-elements, feature/board/board-editor, feature/board/obstacles (all merged into develop)

1. Board Data

Scripts/GamePlay/Data/LevelData/* — [RENAMED from GamePlay/Configs/LevelData/*]
- Moved LevelDataSO, ListLevelDataConfig and ListLevelDataConfigLoader from GamePlay/Configs to GamePlay/Data

BoardData.cs — [NEW]
- Added BoardData, a Width x Height grid (MaxSize 12) where each cell is empty or holds one Nexus ElementEntry, (0, 0) bottom-left
- Added Contains, Get, TryGet, Set, Clear, Occupied and OccupiedCount for cell access
- Added Resize, anchored bottom-left, keeping every entry that still fits

BoardDataCodec.cs — [NEW]
- Added BoardDataCodec on the Nexus BoardCodec base, encoding the grid and passing each cell's element through the Nexus element path
- Reading clamps oversize boards and drops off-board, duplicate or unknown-definition cells with a warning instead of throwing

BoardDataDto.cs — [NEW]
- Added BoardDataDto and BoardCellDto as the JSON shape: width, height and a sparse list of occupied cells

BoxData.cs / HiddenData.cs / IceData.cs / KeyData.cs — [NEW]
- Added BoxData (ColorId from UnitData plus Direction) as the tappable sand box
- Added HiddenData as a data-less feature, IceData with Count (default 1), KeyData with PairId (default Unpaired)
- Marked Count and PairId with [DefaultValue] so a 0 survives the Nexus DefaultValueHandling.Ignore write

LockData.cs / StackData.cs — [NEW]
- Added LockData as an element with PairId, taking its own cell
- Added StackData with Direction and an Elements queue of box entries, carried through the Nexus elements branch via IElementContainer

Direction.cs — [NEW]
- Added the Direction enum (written by name) and DirectionExtensions.ToOffset

LevelDataSO.cs — [MOD]
- Added boardJson (TextArea) with BoardJson, DecodeBoard(IElementCatalog) returning a fresh BoardData, and SetBoard to encode back

----------------------------------------------------------------------

2. Gameplay Elements

BoxElement.cs — [NEW]
- Added BoxElement as a Nexus UnitBase<UnitModel, BoxData> implementing IClickable, with Root / Visual transforms for motion and effects
- Tints lid and body renderers from ColorPaletteSO through a MaterialPropertyBlock and rotates the arrow from Direction
- Publishes BoxTappedSignal or BoxTapRejectedSignal on the scope bus from OnTapAccepted / OnTapRejected
- Added SetVisualActive so cover obstacles can hide the box model

BoxCoverFeature.cs — [NEW]
- Added the abstract BoxCoverFeature<TModel, TData> base: locks the box, hides the box model, shows the obstacle model, listens for BoxCollectedSignal
- Added Uncover, which restores the box model, re-evaluates the box lock and plays a reveal punch

HiddenFeature.cs / HiddenModel.cs — [NEW]
- Added the Hidden Box feature: box is untappable and shows the Hidden model until a box in an edge-adjacent cell is collected
- HiddenModel implements IUnitCondition, satisfied once revealed
- Moved the reveal / punch / visual toggle into BoxCoverFeature once Ice was added

IceFeature.cs / IceModel.cs — [NEW]
- Added the Ice Box feature on BoxCoverFeature: counter shown on the ice model, every collected box anywhere calls Crack, ice breaks at 0

StackElement.cs / StackModel.cs — [NEW]
- Added StackElement that faces Direction and pushes the next queued box into the cell in front on board build and each time that box is collected
- StackModel.TryTakeNext pops the queue; an empty stack shrinks and leaves the board
- Kept boxes in the queue when the front cell is off the board or occupied

KeyFeature.cs / KeyModel.cs — [NEW]
- Added the Key feature: tinted by pair id, detaches when its box is collected, flies to the Lock with the same pair id and opens it

LockElement.cs / LockModel.cs / PairColors.cs — [NEW]
- Added LockElement taking a cell and blocking boxes until its key arrives; TryReserve lets only one key claim it, Open plays the shackle anim then frees the cell
- Added PairColors.ColorIdOf mapping pair id to GDD colours: 0 yellow, 1 red, 2 green, 3 blue, 4+ yellow

RendererTint.cs — [NEW]
- Added RendererTint.Apply, tinting renderers through a MaterialPropertyBlock so instances share one material

ColorPaletteSO.cs — [NEW]
- Added ColorPaletteSO indexed by ColorId, Get returns magenta for an out-of-range id

----------------------------------------------------------------------

3. Interaction / Signals / Views

IClickable.cs / InputController.cs — [NEW]
- Added IClickable ported from Common
- Added InputController as a MonoBehaviourService: raycasts on the Clickable layer on press, skips taps over UI per pointer id, Enable / Disable instead of a static flag
- Takes the camera from GameplaySceneScope on scene load and drops it on unload rather than using Camera.main

BoxTappedSignal.cs / BoxTapRejectedSignal.cs / BoxLeftBoardSignal.cs / BoxCollectedSignal.cs — [NEW]
- Added signals for an accepted tap, a rejected tap, a box gone off screen, and a box collected (box plus cell)

BoardView.cs — [NEW]
- Added BoardView on the Gameplay scene Board root: builds the current level once the level asset loads and again on OnReloadLevel
- Added CellToLocal and CellOffsetToWorld, laying cells on the XY plane centred on the transform

GameContext.cs — [MOD]
- Added elementCatalog and boxMotionConfig fields and RegisterBoardServices, registering ElementScope, ElementSpawner, BoardService and BoxMoveService
- Logs a warning and falls back to defaults when the catalog or motion config is missing

----------------------------------------------------------------------

4. Services

BoardService.cs — [NEW]
- Added BoardService: Build spawns every occupied cell then runs one post-init pass, Clear despawns the whole scope store
- Added TryGetElement / TryGetCell lookups, Vacate to free a cell when a box starts leaving, TryFindBlocker to walk a direction
- Clears the board on OnGameplaySceneUnloading so the store never hands out destroyed elements
- Added SpawnAt and Despawn for elements spawned during play (stack boxes)

BoxMoveService.cs — [NEW]
- Added BoxMoveService listening for BoxTappedSignal: a blocked box bumps into the blocker and back while the blocker shakes; a clear box vacates its cell, flies off screen and raises BoxLeftBoardSignal
- Publishes BoxCollectedSignal before the leave move starts
- Bumps and shakes Root instead of Visual so obstacle models hung beside the box shake with it

LevelDataLoaderService.cs — [MOD]
- Replaced Preserve() on the load chain with a UniTaskCompletionSource per link (RunLinkAsync), fixing "Already continuation registered" when two callers await a pending load

BoxMotionConfigSO.cs — [NEW]
- Added move speed, exit margin, bump and shake timings as placeholder values to tune

----------------------------------------------------------------------

5. Level Editor

LevelDataSOEditor.cs — [NEW]
- Added the LevelDataSO inspector embedding the grid board editor; edits work on a decoded copy and encode back to boardJson in the same Undo step
- Finds the catalog and palette by type, keeps the chosen registry across sessions, redecodes on undo / redo

GridBoardEditor.cs / GridBoardCanvas.cs / GridBoardModel.cs / GridGeometry.cs / GridCells.cs — [NEW]
- Added the grid board editor on the Nexus BoardEditorShell with width / height fields and a tool switch
- GridBoardModel supports Place, Remove, Move, Paint, Select, Resize and ClearAll on BoardData
- GridGeometry lays out cells and hit-tests clicks

GridTools.cs — [NEW]

GridEditorRegistry.cs / GridEditorContext.cs / PaletteColorCapability.cs — [NEW]

BoxShapeDrawer.cs / SmallBadgeShapeDrawer.cs / IceShapeDrawer.cs / KeyShapeDrawer.cs / LockShapeDrawer.cs / StackShapeDrawer.cs — [NEW]
- Added cell drawers: box with direction arrow, corner badge for features, ice badge with count, key badge tinted by pair id (grey with red outline when unpaired), lock tile, stack with arrow and queue preview

StackDataDrawer.cs — [NEW]
- Added the stack inspector: spawn direction, clickable box queue, add / reorder / remove buttons, colour and direction of the selected box

LockKeyPairRule.cs / StackFacingBoardRule.cs — [NEW]
- Added a validation rule for Lock–Key pairs, including keys on stack boxes: missing pair id, lock without key, key without lock, mismatched counts per pair id
- Added a validation rule flagging stacks that face off the board
```
