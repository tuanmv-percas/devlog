PieceConsumeService.cs — [NEW]
- Added PieceConsumeService subscribing to SlotsService.OnSlotFilled
- Looped over slots so each unfilled block consumes its color via ConsumeReachable, removed eaten pieces from PictureView, reduced capacity, freed the slot when full
- Repeated the pass until no block eats more, so a waiting block auto-eats once another block opens its color
- Added Bind(pictureView, slotViews) called by GameController

SnakeService.cs — [MOD]
- Added _snakeSpawnEnabled flag (default false) gating HandleSpawnPhase so no snake emerges when a block settles into a slot
