# ant-hustle

```
1. Road & Ant Scale

AntSpawner.cs — [MOD]
- Ant model scale raised from 0.9 to 0.99; every ant-body spacing scaled by 1.1 (lanes, rows, trail follow gap, edge path, peek ring, arm spacing, climb length, hole clearance, separation, block attach ring)
- LeadOffset, TrailMargin, AntBellyReach and PeekBodyLength constants scaled by 1.1
- Outer rail moved from 0.92 to 1.0 to clear the wider outer lane; hole mouth radius from 0.65 to 0.72

LevelManager.prefab — [MOD]
- Road halfStraight reduced from 3 to 2 at the same radius, so the road is about 13% narrower (about 32 columns instead of 41)
- Road padding raised from 30 to 95 per side so CameraFit keeps the fit scale instead of scaling the shorter road up

Ant.prefab — [MOD]
- Model scale set to 0.99

----------------------------------------------------------------------

2. Hole Waiting Line & Climb-out

AntSpawner.cs — [MOD]
- ClimbOut joins the straight climb-out to the spiral trail with a Hermite curve matching both ends, removing the up-to-60-degree snap after leaving the hole and the 19-degree turn at climbLength
- The join meets the trail at least one body length past the straight; the straight runs 0.15 further
- Ants keep their climb-out speed when leaving the hole instead of stalling at the rim
- Each exit gets its own waiting line down the hole wall that takes the next rows even while the road is full
- Added Ring line style (new default): waiting ants stand in fixed rim slots under their arm's trail, climb out from their own slot, and a freed slot is refilled from below; Spiral style kept behind lineStyle
- Climb-over tilt uses smoothstep, rising ants brake into the rim, the peek bob fades in
- Ants queued deeper than the hole bottom are drawn just below it
- holeRadius raised from 0.72 to 0.95; ringGap set to 0.58, then 0.7 — each arm now holds four waiting ants (eight in total)
- peekCount set to 2 so each of the two arms has one waiting ant at its exit

RoadSpawner.cs — [MOD]
- Added holeDepth (4.5) and holePit fields with HoleDepth getter
- ApplyHoleDepth() stretches the hole_pit mesh along its depth axis so the waiting line is visible

Hole.prefab — [MOD]
- Added MouthMaskWide depth mask so deep ants never show below the hole
- MouthMaskWide moved 0.25 below the road plane so it no longer clips the legs of ants walking near the hole

----------------------------------------------------------------------

3. Level Intro

AntSpawner.cs — [MOD]
- Road is prefilled from the level queue at level start
- Added IntroStyle.Appear (ants pop up in place) and IntroStyle.Pour (ants climb out on the side facing their slot and crawl to it, outer lane first)
- Pour climbs out in one stream per rim slot, then steers to the road spot; the waiting line is the tail of those streams so it follows without a pause (speed 8, start 5, acceleration 40)
- Added IntroStyle.None: road placed full and waiting lines already peeking at the rim
- Intro waits for LevelTransitionService.IsCovering to clear and PreLoaderScreen to close before placing ants; the Level Editor still starts at once

Ant.cs — [MOD]
- Added PlayAppear(delay, duration): scales the model from 0 with an OutBack ease

LevelManager.prefab — [MOD]
- Intro style set to None

----------------------------------------------------------------------

4. Road Column Assignment

AntSpawner.cs — [MOD]
- A waiting row can take any empty road column, not only one passing the arm's merge point at arrival; ants chase the column along the inner edge
- Removed LeadMin / LeadMax window, Fits() and Arm.LastRow
- Added EdgeSlack (0.2), EdgeDelay() and ForwardGap(); column choice scores edge travel time minus BesideBonus (1.5 s) for columns next to the same colour
- Added SectorLength() and EdgeTravel(): each arm only uses columns reachable inside its own edge sector, ending SectorMargin (1.5) before the next arm's merge point, so the two arms' ants never overlap on the edge

LevelManager.prefab — [MOD]
- crawlSpeed 4.5 -> 6.5, trailAcceleration 8 -> 14, edgeSpeed 5.5 -> 8, stepSideSpeed 3.5 -> 4.5

----------------------------------------------------------------------

5. Dock Layout

DockSpawner.cs — [MOD]
- Added Spread(width): spaces slots evenly across the given width, capped at DockConfig.MaxSpacing; shrinks the slots when a gap of MinGap cannot fit
- Added SlotWidth() measured from the slot model renderers

DockConfig.cs — [MOD]
- Added minGap (0.5 of a slot width) and maxSpacing (2 board pitches)

DockSlot.cs — [MOD]
- Added Size, Model and SetSize()

CameraFit.cs — [MOD]
- Added dockPadding (95 canvas units, matching the road); the dock row is laid out between the paddings via DockSpawner.Spread

BlockVisual.cs — [MOD]
- Blocks landing in a slot scale by DockSlot.Size

----------------------------------------------------------------------

6. Block Carry

BlockVisual.cs — [MOD]
- Replaced the LitMotion pull tween with a per-frame StepCarry(): the group has its own velocity, steers to a point carryLookAhead ahead on the path and changes velocity by at most carryGrip, so it drifts wide on corners
- Added PathPoint(), FinalDirection() and CarryOvertime (1.5 s) for corner overshoot
- PlayPullAway takes a reverse path: ants lift the block, back it tail-first into the gap under the dock, swing it toward the far side while turning its nose to the exit, pause, then drive it off screen
- Path is parametric with smootherstep speed; the group follows it through a damped spring for inertia
- Block leans 8 degrees from the turn onward and wobbles with the ants' steps in every phase
- Added HideCount(); the count fades out at 0

AntSpawner.cs — [MOD]
- Carry path split into CarryReverse (cubic Bezier backing down and sideways) and CarryPoints (forward run to the screen edge)
- Added carryTurnRadius (0.25) for the sideways swing at the end of the reverse
- Calls HideCount() when the remaining count reaches 0

Block.prefab — [MOD]
- liftDuration 0.25 -> 0.18, carrySpeed 4.5 -> 7, carryRamp 0.3 -> 0.35
- Added serialized carryReverseSpeed, minReverseDuration, carryShiftPause, carryTurnStart, carryInertia, carrySwayFrequency, carrySwayDamping, carrySwayMax, carryYawSwayMax so stale in-memory defaults cannot override them

LevelManager.prefab — [MOD]
- Serialized carryTurnRadius
```
