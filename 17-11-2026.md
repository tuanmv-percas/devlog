# color-sand-block

```
1. Linked Block — Gameplay

LinkData.cs — [NEW]
- Feature data for a link: ties one end of this block to an end on another block
- LinkCorner covers the four corners plus the four side middles (Top/Right/Bottom/Left = 4-7); existing levels keep their values

SandElementIds.cs — [MOD]
- Added feature id Link = "link"

IDragTether.cs — [NEW]
- Interface for anything that holds a dragged block within a distance; BlockDragInput reads each tether every step
- Slows the block as the rope draws tight; a tether that breaks mid-drag lets go at once

BlockLink.cs — [NEW]
- Runtime pair of linked blocks with their ends; side-middle ends added in the second commit

LinkFeature.cs — [NEW]
- Feature behaviour on the block: builds the rope, registers the drag tether, breaks the rope when one block clears
- Added the limit warning on the holding block from LimitFrom (2.9 squares): LimitWarning = Lean, Glow, None or LeanAndGlow
- Lean tips the holder's art towards the dragged block on a spring (LeanAngle 6, pivot 60% up its side), shudders at full stretch and rocks back when the pull lets go
- No warning shows when no linked block is being dragged

LinkGeometry.cs — [NEW]
- World positions of link ends on a block; side-middle dots are inset only from the outer edge they sit on

LinkModel.cs — [NEW]
- Pure model of a link's length and allowed distance, shared by the drag tether and the rope

LinkRope.cs — [NEW]
- Rope hangs with a slight sag on a spring and grows in with its blocks at level start
- Shaded as a tube lit from above with ball ends; outlines drawn under every fill so the rim runs unbroken into the dots, drawn over a held block's outline
- Rope middle held within the slack left, so a rope at full length is straight that frame; swing spring stiffens as the link draws tight (TautFrom, TautStiffness, SwingRoom) and is stepped in small steps
- Past StretchFrom the coloured core thins like a rubber band, most at the middle, down to StretchThin at full length; dark rim and end dots keep their size

LinkRope.Break.cs — [NEW]
- Break sequence when one block clears: rope pulls straight, tugs the other block (BlockElement.SetTug) and snaps
- Break strain starts from the thinned width

LinkGlow.cs — [NEW]
- Red glow round the block holding a dragged block back, built like QuickOutline: outer walls pushed out along smoothed normals in eight fading rings
- LinkGlowMask marks every block while the glow shows, so the glow lies on the board and never over a block; partitions and the badge are masked but not glowed; nothing drawn below the board's bottom edge
- Cover over the blocks' open insides laid on every block, again each frame, and moved with a held block's lift (was only on the glowing block, only when the glow came on)
- Each glow now owns its own mask copy; with one shared, the first glow to go out unmasked every block and a still-glowing block was painted red inside and out
- Inside cover reaches a little further so it stays closed over a leaning block

LinkSettings.cs — [NEW]
- Tunables for rope, drag and break; added TautFrom, TautStiffness, SwingRoom, StretchFrom, StretchThin
- Added Drag > Limit glow: GlowColor, GlowWidth, GlowBlink, GlowBlinkSpeed; GlowColor alpha set to 0.35
- GlowFrom renamed to LimitFrom with FormerlySerializedAs; added LimitWarning and lean settings

BlockDragInput.cs — [MOD]
- Collects the held block's tethers and applies them every drag step
- Remembers the last allowed snap cell from where the body actually is after physics, so a wall never counts
- A tethered block released over a disallowed cell goes back to the last allowed cell it passed, or its pick-up point
- A block pulled taut every way only shakes (StuckProbe 0.05 cells)

BlockElement.cs — [MOD]
- Added PlayRefusal() for a refusal decided outside the block (only on a block at rest)
- Added SetTug(worldOffset): moves the block's art by a rope yank without moving the block; cleared on reset
- Added TryGetRimDepth() for the top of the block's walls, used to place the glow and cover
- Added SetLean(): applies the lean turn on top of the holder's other transforms and removes it again; skipped while the level intro plays

GridController.cs — [MOD]
- Split SnapToCell into SnapTo(block, centre) so a linked block can be snapped to a caller-chosen cell
- Added TryGetSnapCentre(): false off the board, on a wall or on a non-walkable cell

GameHaptics.cs — [MOD]
- Added LinkBreak = RigidImpact for the rope snapping

Elements/README.md — [MOD]
- Documented the Linked Block feature, drag tether and end points

----------------------------------------------------------------------

2. Linked Block — Art / Shaders

LinkRope.shader, link-rope.mat — [NEW]
- Rope shader: tube shading lit from above, rim and core colour, stretch thinning

LinkGlow.shader, link-glow.mat — [NEW]
- Percas/LinkGlow: ring-based soft glow pushed out along smoothed normals, blinking

LinkGlowMask.shader, link-glow-mask.mat — [NEW]
- Percas/LinkGlowMask: stencil mask over blocks so the glow never draws on top of them

FeatureIcons/link.png — [NEW]
- Level editor icon for the Link feature

----------------------------------------------------------------------

3. Prefab Updates / Config

link.prefab — [NEW]
- Link feature prefab with LinkSettings; rope settings serialised, Drag > Limit glow values added, LimitWarning = LeanAndGlow

link.asset, SandElementCatalog.asset — [NEW] / [MOD]
- Element definition for the Link feature and its catalog entry

Link_Test.asset — [NEW]
- Test level for linked blocks

LinkSetup.cs — [NEW]
- Editor setup script that creates the link prefab, definition and catalog entry

----------------------------------------------------------------------

4. Level Editor

LinkMode.cs — [NEW]
- Board mode opened from a block: starts a rope from one of its end points and snaps the other end to a point on another block; one click does one thing
- Offers all eight points per square (corners and side middles)

LinkOps.cs — [NEW]
- Add / remove links on a level; DropBlock() removes a deleted block's links from the blocks at the other ends too

LinkArt.cs — [NEW]
- Draws ropes and end dots on the editor board; side-middle dots supported

LinkRule.cs — [NEW]
- Validation: rope length, reused end points, orphaned links

FeatureConflicts.cs — [MOD]
- Link conflicts with Hidden (rope wears the block's colour) and Sticky (a stuck pair drags as one)

LevelEditorView.cs — [MOD]
- Link button in the block's feature row opens LinkMode instead of toggling data; label counts the block's links
- DrawLinkDetails(): next-step hint while linking, last result, list of the block's links with a remove button
- Link mode ends when another block or none is selected; Esc leaves link mode before dropping the block

LevelBoardModel.cs — [MOD]
- Added EditLinks() wrapping link edits in one undo step; block delete drops its links

LevelBoardCanvas.cs — [MOD]
- Exposed BoardGeometry for modes that read the pointer between squares

FeatureArt.cs — [MOD]
- Link is drawn as a rope (LinkArt), not counted or drawn as a badge

ObstacleKinds.cs — [MOD]
- Added "Linked Block" to the data export obstacle names
```
