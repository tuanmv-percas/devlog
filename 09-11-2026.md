# color-sand-block

```
1. Hidden Block Obstacle

HiddenData.cs — [NEW]
- New feature data with Blocks (number of other blocks that must clear before reveal), [Min(1)], implements IDataClonable

HiddenModel.cs — [NEW]
- Implements IFeatureModel and ICollectRule: CanCollect is false until Remaining reaches 0, so the block takes no sand but can still be dragged
- Init() clamps Blocks to at least 1; CountClear() decrements Remaining and stops at 0

HiddenFeature.cs — [NEW]
- Listens to BlockCompletedSignal and BlockStageCompletedSignal: every other block clearing (inner block of a double included) counts one down
- Shows one cover per block shape (m_Shells, matched by ShapeIndex) and hides the block's own art with SetVisualActive(false); counter label kept upright via UprightRotation
- Tick tween (scale 1.06) on each count, label pop (1.25), reveal sequence: pop to 1.1, show the block, shrink cover to 0, then Detach()
- Cover scales about the centre of its footprint (FindPivot from the cover renderer bounds) so L and long shapes do not reach over one side
- Shapes with no cover keep their own art and log a warning
- Added Lid and Outline fields per cover; implements IOutlineArt with SetOutline(on, width) to outline the cover while held
- SetUpMarks() passes _MarkSpace (upright cover space in board squares), _CounterPos and _BlockSeed (from block position) to the lid via MaterialPropertyBlock
- FlattenRim() rewrites lid outline normals in UV3 with the up component removed so the outline goes round the lid; runs once per mesh

SandElementIds.cs — [MOD]
- Added Hidden = "hidden" and Sticky = "sticky" ids

----------------------------------------------------------------------

2. Hidden Block Art

HiddenLid.shader — [NEW]
- New Percas/HiddenLid shader: lid atlas with question marks stamped on the top face only (_TopFacing threshold)
- Top split into slots on the board grid (_MarkSlots per square per side); each slot holds at most one mark with hashed chance, size jitter, position jitter and tilt, kept inside the slot so marks are never cut at the edge
- Marks stay _CounterClearance away from the counter; pattern seeded by _MarkSeed + per-block _BlockSeed

hidden_lid.mat — [NEW]
- Material on Percas/HiddenLid with the tunable mark settings

hidden.mat — [NEW]
- Cover body material; switched from placeholder grey to the hidden_body texture

hidden_body.png, hidden_lid.png, hidden_mark.png — [NEW]
- Grey body texture, lid atlas and question mark alpha texture

hidden.prefab — [NEW]
- Hidden feature prefab with one cover per block shape 0-8, each with counter label; covers rebuilt from the block's own body shape with a lid and a disabled Outline component

hidden.png (FeatureIcons) — [NEW]
- Level Editor icon for the hidden element

lid/1.fbx ... lid/9.fbx (.meta) — [MOD]
- Enabled Read/Write on lid meshes so the outline can read them on device

----------------------------------------------------------------------

3. Sticky Block Obstacle

StickyData.cs — [NEW]
- New feature data with a pair Id; two blocks with the same id move as one

StickyModel.cs — [NEW]
- Holds Id and IsLinked with Link() / Unlink(); not a collect rule, a stuck block takes sand normally

StickyFeature.cs — [NEW]
- OnPostInit() finds the other unlinked block with the same id through the element store and links both sides (SetDragPartner on each BlockElement)
- BuildConnectors(): finds board cells covered by each block via CoversPoint, places a connector on every shared edge, rotated per edge direction
- Connectors take the colour of the bigger block (coin toss on equal size) and are parented under that block's FeatureRoot so they lift with the pair
- Either block clearing (BlockCompletedSignal) breaks the bond; connectors are left on the board and scale out with InBack over 0.15 s
- Logs a warning when no partner is found or the two blocks share no edge

sticky.prefab, sticky.mat, sticky.asset — [NEW]
- Sticky feature prefab with an inactive connector template, connector material and element definition

sticky.png (FeatureIcons) — [NEW]
- Level Editor icon for the sticky element

----------------------------------------------------------------------

4. Block Drag / Element Core

BlockElement.cs — [MOD]
- Added dragPartner, isPairTogether and isBusy properties and SetDragPartner()
- CarryPartner(): on pickup the partner is reparented under the held block, its Rigidbody2D stops simulating, and its drag boxes are copied as stand-in BoxCollider2D on the held body so the pair collides as one shape
- ReleasePartner(snap): removes the stand-in boxes, restores the partner's parent and frozen rigidbody, and snaps it to its cell via GridController.SnapToCell
- A partner held shut (not IsOpen) blocks the pair and plays its blocked feedback; a partner on a rail adds its frozen axes to the held block
- Partner filled mid-drag leaves the pair where it stands; Clean() releases the partner before pooling
- Added introCentre: the intro pivot of a stuck pair is the centre of both footprints so the pair pops in on one beat
- Added CoversPoint() and AddWorldBoxes() helpers based on the two drag boxes
- ActiveOutline() now calls IOutlineArt.SetOutline() on every feature that draws the block in its place

IOutlineArt.cs — [NEW]
- Interface with SetOutline(on, width) for features whose art replaces the block body

BlockDragInput.cs — [MOD]
- Drag holds in place while isPairTogether is false (partner dropped out mid-drag)
- Pickup check uses isBusy on the block and on its drag partner

BlockController.cs — [MOD]
- Intro wave delay measured from block.introCentre instead of footprintCentre

LayoutConfig.cs — [MOD]
- m_BlockDragLift default changed from 1 to 1.5 so a held block clears the hidden lids; tooltip notes the hidden block height (~1.21)

LayoutConfig.asset — [MOD]
- BlockDragLift set to 1.5

----------------------------------------------------------------------

5. Level Editor

ClearGateReachRule.cs — [NEW]
- New validation rule for blocks gated on other clears (Hidden, Ice): iteratively opens gated blocks whose count the available clears cover and reports the rest as errors (too few blocks or circular waits)
- Double-color blocks count as two clears; warns when Hidden Blocks <= 0

StickyPairRule.cs — [NEW]
- Errors when a sticky id is not on exactly 2 blocks, or when the two blocks do not touch edge to edge (corner contact does not count)

FeatureConflicts.cs — [MOD]
- Added conflicts Hidden + Ice, Hidden + AxisLock and Sticky + Hidden

FeatureArt.cs — [MOD]
- Hidden blocks drawn with a grey veil and a chip showing Blocks; DrawFrost() generalised into DrawWash(color) shared with Ice
- Sticky blocks wear a pair-coloured chip with the sticky id, same as key/lock pairs

BlockPlacementRule.cs — [MOD]
- FillFootprint() made internal static so StickyPairRule can reuse it

DataFields.cs — [MOD]
- Added ApplyMin(): [Min] attribute now enforced on int and float fields in the board inspector

----------------------------------------------------------------------

6. Config / ScriptableObjects

hidden.asset — [NEW]
- ElementDefinition for hidden (category 4, display name Hidden, icon and prefab assigned)

SandElementCatalog.asset — [MOD]
- Registered hidden and sticky element definitions
```
