```
1. Hidden Block Obstacle

HiddenModel.cs — [NEW]

HiddenFeature.cs — [NEW]
- Listens to BlockCompletedSignal and BlockStageCompletedSignal: every other block clearing (inner block of a double included) counts one down

- Shapes with no cover keep their own art and log a warning
- Added Lid and Outline fields per cover; implements IOutlineArt with SetOutline(on, width) to outline the cover while held
- SetUpMarks() passes _MarkSpace (upright cover space in board squares), _CounterPos and _BlockSeed (from block position) to the lid via MaterialPropertyBlock

# ant-hustle

```
1. Block Traffic

BlockTraffic.cs — [NEW]
- New shared traffic queue for blocks that have left the board: running into a slot, parked in the dock, and carried off by ants
- Each block is a Traveler holding a Ticket ordered by when it started moving; a carried block takes a new ticket when the ants start carrying
- Rule: a later ticket never steps onto the remaining path (current position and final parking spot included) of any earlier ticket; earlier tickets never look back
- Enqueue exception: a new block whose start position already lies on an earlier block's remaining path goes first, and the earlier one waits
- Every block, long ones included, counts as one square the width of its body, so long blocks may brush edges but never deadlock
- Traveler.Reserve holds the back-out area of a parked block so other carried blocks wait outside it

BlockVisual.cs — [MOD]
- Exit run into the slot now steps every frame (StepExit) on its own profile clock instead of a MotionHandle tween, so it can slow down, stop and pull away
- Added Govern(): caps speed at sqrt(2 x trafficBrake x free distance) with an exponential settle (trafficSettle) and SmoothDamp rate change (trafficEase); a hard brake never overshoots the stop point
- Added trafficBrake (30), trafficSettle (0.12), trafficEase (0.12), trafficLookahead (3), runClearance (0.04) and carryClearance (0.12)
- SampleExitPath() and SampleCarryPath() split the run and the carry path into world footprints for BlockTraffic
- Carry path now runs on carryClock, which only advances as fast as BlockTraffic allows; the ants keep straining while waiting
- Added EvaluateExit() (pure pose at a path cost) and FaceAlong() now returns a rotation instead of writing the transform
- bodyHalfSize read from the collider width (0.84 per cell) for the traffic footprint

AntSpawner.cs — [MOD]
- Added CarryReserve(): the area a parked block will take while backing out and turning, widened for sideways shift and the turn
- CarryPath() takes the carried block, exit direction and leader; backs out deeper so it passes fully under long blocks parked in neighbouring slots (DockClearDepth)
- Added CarryAway(): end slots leave on their own side, middle slots on the nearer side, and switch to the other side when the default side is blocked by a long parked block and the other side is clear

Dock.cs — [MOD]
