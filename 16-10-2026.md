# bus-down

```
1. App Startup / Warmup

Scripts/App/Warmup/AppWarmupService.cs — [NEW]
- Warm-up service that runs while the preloader is still covering the screen: compiles the ShaderVariantCollection progressively, loads popup prefabs through Addressables and prewarms the object pool
- Each step runs through RunStepAsync, which logs its duration and swallows exceptions so a failing step never blocks entry into the game
- Exposes Progress, the ProgressChanged event and the Completion UniTask; progress weights are 0.4 shader, 0.3 presentation, 0.3 pool
- Shader step is skipped in the Editor because source compilation there is not representative of devices
- Keeps the AsyncOperationHandle of every preloaded popup prefab for the whole session; logs a warning and releases the handle when a prefab fails to load

Scripts/App/Warmup/WarmupConfig.cs — [NEW]
- ScriptableObject holding m_PoolConfig, m_ShaderVariants, m_ShaderVariantsPerFrame (default 8) and the m_Presentations list of type names to preload

Scripts/App/Warmup/WarmupConfigLoader.cs — [NEW]
- AddressableContentLoader for WarmupConfig so it can be registered in the Config Registry loaders list

Scripts/App/GameContext.cs — [MOD]
- Added InstallWarmup: creates the app-scope GamePool from WarmupConfig.PoolConfig, registers it and AppWarmupService in the ServiceLocator, then starts the warm-up immediately

Scripts/App/GameplayInstaller.cs — [MOD]
- PooledElementFactory now takes the app-scope GamePool from ServiceLocator instead of creating a new GamePool(null) per Gameplay scene, so a level no longer leaves its own [Pools] root behind

Scripts/GlobalState/GlobalStateMachine.PreLoaderState.cs — [MOD]
- ApplicationLoadFinished now awaits AppWarmupService.Completion before switching to InGameState
- Added the _isActive flag so the state does not switch if it was exited while still waiting on warm-up

Scripts/SceneFlow/BootstrapLoadingScope.cs — [MOD]
- Split the loading bar: startup pipeline fills 0–70% (StartupProgressShare), warm-up fills the remaining 30%
- Added WaitForWarmupAsync, which holds the preloader until warm-up completes and unsubscribes HandleWarmupProgressChanged on destroy
- Forced Application.targetFrameRate to 60 and QualitySettings.vSyncCount to 0 right after StartupDisplay.Configure, overriding the 60–75 fps it picks from the display refresh rate

Scripts/SceneFlow/GameSceneFlowService.cs — [MOD]
- Added ReleaseGameplayObjects: calls BoardService.Clear, deactivates every root of the Gameplay scene, then GamePool.ReleaseAll
- Called before reloading the Gameplay scene and before unloading it, so the new scene borrows the same instances and the old scene stops touching them

Scripts/Pooling/Scripts/PoolService.cs — [MOD]
- Added Prewarm(prefab, count) for prefabs not declared in the pool config
- Added GetConfiguredPrewarmCount, the total instance count requested by the config

Scripts/SnakeFlow/Pooling/GamePool.cs — [MOD]
- PrewarmAsync now takes an onProgress callback and reports progress from the configured prewarm total and PrewarmPerFrame
- Added Prewarm(Component, count), SpawnFx (spawns a cleared, stopped ParticleSystem) and PlayAndRecycle, which plays the fx and returns it to the pool after its lifetime
- RecycleAfterAsync uses the per-borrow despawn token so an fx collected early by ReleaseAll is not returned twice

2. Board / Columns / Elements

Scripts/SnakeFlow/Columns/BoardService.cs — [MOD]
- Clear now despawns every element still left in the store (e.g. a Block parked in a slot) before clearing it, so pooled instances are cleaned and returned
- Passes renderedCount = ceil(LayoutConfig.MinVisibleElements) to BoardView.Init

Scripts/SnakeFlow/Columns/BoardView.cs — [MOD]
- Init takes renderedCount and forwards it to each ColumnView

Scripts/SnakeFlow/Columns/ColumnView.cs — [MOD]
- Added RefreshCulling, called on add, remove and reindex: elements beyond the first renderedCount slots of the column are culled
- Init takes renderedCount; 0 or less renders everything

Scripts/SnakeFlow/Columns/ColumnElement.cs — [MOD]
- Added IsCulled and SetCulled, which toggles forceRenderingOff on every child Renderer through a shared static list without changing enabled/active state
- Clean un-culls the element so a pooled instance is not invisible on its next use

Scripts/SnakeFlow/Columns/Elements/BlockElement.cs — [MOD]
- Clean drops the cached ColorService and ReachablePieceService, which are rebuilt per Gameplay scene
- Clean sets OnClick to null; a pooled Block reused in the next level kept the old BlockDispatchService handler, which called ShakeDeny and made the Block appear to jump into the slot
- Tap sfx changed from UFO_TAP to BLOCK_TAP, suck sfx from UFO_SUCK to SNAKE_EAT

Scripts/SnakeFlow/Columns/Elements/ElementEffect.cs — [MOD]
- Added PlayPooled(prefab, anchor): borrows the VFX from GamePool, copies the anchor position, rotation and local scale, then plays and recycles it; falls back to PlayCopy when no prefab or pool exists

Scripts/SnakeFlow/Columns/Elements/BlockIce.cs — [MOD]
- Added m_BreakEffectPrefab; break VFX now plays through ElementEffect.PlayPooled

Scripts/SnakeFlow/Columns/Elements/BlockHidden.cs — [MOD]
- Added m_HiddenEffectPrefab; reveal VFX now plays through ElementEffect.PlayPooled

Scripts/SnakeFlow/Columns/Elements/LockElement.cs — [MOD]
- Added m_UnlockVfxPrefab; unlock VFX now plays through ElementEffect.PlayPooled
- Added m_OpenPeakTime (0.2667s): the Unlock clip is frozen at the moment the shackle is fully open, and the lock shrinks from that pose instead of closing again first
- Added OpenDurationFor and FreezeUnlockClip; clip speed is reset to 1 every time the clip is played or rewound

3. Piece Movement / Picture Frame

Scripts/SnakeFlow/PieceMovement/PieceMovementService.cs — [MOD]
- Bind takes frameSideMargin and frameSideInset; TryMeasureFrameColumns replaced by TryMeasureFrameSides, which measures the frame side edges in world units from the screen edge plus the frame inset in cells
- Frame measurement now returns true even when the viewport is too narrow for any column
- Added SetBoardCleared and _speedMultiplier; added the MaxSpeed property used for ORCA solve, steering, velocity clamp and desired speed
- Last-round multiplier also scales acceleration, divides gateCaptureInterval, enterBlockDuration and enterLeanDuration, and lets the move animation ratio go above 1

Scripts/SnakeFlow/PieceMovement/PieceGrid.cs — [MOD]
- Added _frameLeftX and _frameRightX, the real side edges of the frame interior in picture-local cells
- SetFrame takes leftEdge and rightEdge; when the minimum 1 column per side pushes a column out, the edge moves out with it
- Added GetFrameSideEdges plus the ColumnLeftX and ColumnRightX helpers

Scripts/SnakeFlow/PieceMovement/PieceMovementConfig.cs — [MOD]
- frameGap now only controls the rows above the grid; the horizontal meaning was removed
- Added lastRoundSpeedMultiplier (default 1.5)

Scripts/SnakeFlow/PieceMovement/PieceAvoidanceSimulator.cs — [MOD]
- Step and SolveAgent take maxSpeed as a parameter instead of reading config.maxSpeed

Scripts/SnakeFlow/View/PictureFrameView.cs — [MOD]
- Added m_SideScreenMargin (default 0.3 world units) and the SideScreenMargin / SideInset properties
- BuildFrame places the side bars from PieceGrid.GetFrameSideEdges instead of the edge column centres, so both sides sit a fixed distance from the screen edge on every level

Scripts/SnakeFlow/Controllers/GameController.cs — [MOD]
- Passes the frame side margin and inset into both PieceMovementService.Bind calls
- Forwards the last-round state to PieceMovementService.SetBoardCleared and resets it on level start
```
