# bus-down

```
1. Piece Movement

PieceMovementService.cs — [MOD]
- Rewrote the movement loop to run entirely on own code: static A* route + acceleration-limited steering + ORCA avoidance, simulated in picture-local space (1 unit = 1 cell, no world-scale conversion)
- Write localPosition directly instead of converting to world and back, since pieces stay parented to the picture's piece root (identity local transform)
- Track slots with pieces in flight in a list kept alongside _inFlight so the gate sink no longer builds a key collection every frame; freeing a slot now drops its capture timestamp
- Integrated the walkable clamp so moving pieces are pushed out of blocked cells
- Exposed the gate cell lookup (derived from the slot column) for the consume service
- Added re-path: a piece that stops advancing gets a fresh A* route from its current cell; progress measured along the path, not by speed; re-paths capped per frame
- Count a whole reserved wave into the slot's in-flight tally so a block stays alive between layers; Tick reports busy from that tally, not the live agent list
- Gate now drains every piece inside gateCaptureRadius in one go, nearest-along-path first; next-pulse scheduling made conditional so a slot dropped mid-loop is not left stranded

PieceAStar.cs — [MOD]
- 8-neighbour search with no corner cutting, octile heuristic, per-cell binary heap with decrease-key so the node budget stays bounded

PieceGrid.cs — [MOD]
- Added cell/local conversion and a nearest-walkable clamp; walls resolved here rather than as solver constraints
- Walkable clamp now pushes the piece centre away from each blocked orthogonal neighbour by the piece radius; out-of-grid counts as blocked; a one-cell channel stays passable
- Stretched the grid's bottom band to the gate row so it clears the slot's top edge by gateRowGap cells; WorldToRow returns a fractional row measured against the slot background renderer bounds

PieceMoveAgent.cs — [MOD]
- Heading now follows the intended direction whenever the rotation filter reports no usable movement, unsticking pieces pressed against a wall
- Added per-piece progress tracking for the re-path check

OrcaSolver.cs — [MOD]
- Replaced AddObstacle/AddAgent with a single AddAgent taking avoidanceStrength; removed the static-obstacle line concept (walls handled by the grid clamp)
- Constraint radius fades to 0 for neighbours beyond one time horizon and the horizon stretches by estimated time-to-collision, so pieces dare to enter narrow gaps
- Overlapping agents separate softly via SolveOverlap (SeparationTimeStep, SeparationStrength) instead of the hard SolveCollision bump
- Added BiasDesiredVelocity to rotate the desired velocity right when it sits inside a forbidden zone, breaking head-on standoffs; added DistanceInsideVolumes and LineCount

PieceMovementConfig.cs — [MOD]
- New fields for the steering/avoidance system, the re-path progress check, and gateRowGap for the grid stretch
- gateCaptureInterval dropped to 0 (now paces bursts, not individual pieces); gate drains by radius
- generationDelay given its intended meaning for layered wave release
- Explored shortening the steering lookahead to 0.8 cells, then reverted to 1.5 after testing showed no improvement

PiecePathFollower.cs — [NEW]
- Lookahead cursor along the A* route plus remaining-distance tracking

PieceSteering.cs — [NEW]
- Acceleration to reach a point, velocity clamp, and a rotation filter

PieceAvoidanceSimulator.cs — [NEW]
- Spatial-hash neighbour search, overlap separation applied outside the ORCA solve, and an ORCA step returning a target point plus speed

----------------------------------------------------------------------

2. Services

ReachablePieceService.cs — [MOD]
- Support for consuming candidates nearest the gate first
- ConsumeLayered reserves several layers up front and releases them as waves: floods a scratch copy of the scanned array seeded from the taken layer's cells; a reserved set that Add now skips stops a second same-colour block poaching a spoken-for layer

PieceConsumeService.cs — [MOD]
- ConsumeCurrent takes the gate cell and sorts candidates by straight-line distance to it, using a prebuilt comparison delegate to avoid per-sort allocation
- Skip a slot when the gate lookup fails (picture not bound) instead of handing pieces to the movement service, which would destroy them
- Moved Detaching, MarkEaten and OpenCell from selection time to the moment a layer is released; calls MarkEaten as each piece detaches

BoardService.cs — [MOD]
- Added HasBlockWithExit, reading the same ActiveElements set HasExit uses, for the lose check

PictureService.cs — [MOD]
- Added MarkEaten, the bookkeeping half of Eat without the view removal, called by the consume service as it detaches each piece
- Clear check drops its snake term

----------------------------------------------------------------------

3. Controllers

GameController.cs — [MOD]
- Re-wired win/lose for the reachable-piece mechanic: evaluated when the piece system goes idle, gated on the intro having finished
- Lose means no remaining way for the board to change: nothing in flight, no block in a slot still going to do something, no block the player could still move into a slot; accounts for spent-capacity blocks still animating, blocks still flying into a slot, and paired sticky blocks needing two free slots
- Moved grid binding to InitSlots (SlotViews has no SlotView to measure until SlotsService.Init has run)

----------------------------------------------------------------------

4. Elements

BlockElement.cs — [MOD]
- ReduceCapacity is now purely the reservation, moving RemainingCapacity only and leaving the label alone
- Added NotifyPieceArrived to step the displayed number down by one, with its punch, as each piece lands; drives the label from _displayRemaining

----------------------------------------------------------------------

5. Pictures / View

PictureView.cs — [MOD]

SlotView.cs — [MOD]
- Expose the slot background bounds so the gate row can be measured against the topmost slot

GameplayInstaller.cs — [MOD]

8. Editor / Build Tool

BuildConfig.cs — [NEW]
- Holds build settings in EditorPrefs keyed by product name so keystore passwords stay on the machine that typed them
- Forces the six provider defines the project ships (Firebase, Adjust, Facebook, GameAnalytics) in RequiredSdkDefines rather than leaving them to a checkbox; Load merges defines already in ProjectSettings back into the list

BuildExecutor.cs — [NEW]

BuildScript.cs — [NEW]

BuildWindow.cs — [NEW]
```
