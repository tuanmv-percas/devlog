# color-sand-block

```
1. Boosters / Commands

BlockFillBoosterCommand.cs — [MOD]
- Magnet and Vacuum draw each block's owed grains over PullSeconds along PullCurve instead of taking all of them in one frame
- Pulled grains fly PullFlightSeconds with random jitter; Vacuum staggers its blocks by VacuumStaggerSeconds, picked block first
- Pull pauses while a popup is open, ends as soon as the colour runs out, and caps how far one frame can advance it
- Pulled grains start moved along the camera view axis to just in front of the picture frame (PullFrameClearance), so they no longer cut through the frame walls
- Each block that takes grains in a frame now counts as one block drawing at full rate, so the pull plays sand_fall at a normal draw level

MagnetBoosterCommand.cs — [MOD]
- ExecuteAsync now plays the magnet anim: fly-in from the Magnet button, block shake, sand stream, shrink-out as the last grains land
- Added HoverPoint/Anchor/BoxRect to place the magnet over the elbow square of an L block, on the camera line of sight
- Clear() hides the magnet and restores the block position when the board is cut mid-anim

VacuumBoosterCommand.cs — [MOD]
- Removed the old doc comment describing the one-shot fill order

----------------------------------------------------------------------

2. Boosters / Fx and Settings

MagnetView.cs — [NEW]
- New view for the magnet: arc flight, rock while pulling, shrink-out, and a rippling distortion field under it
- Builds a primitive placeholder model when no prefab is set; uses MagnetAnimSettings.Prefab otherwise
- Fly-in path changed to: rise from the button to the middle of the screen (0.4 s), spin one turn about its up axis (0.7 s), drop onto the block (0.35 s)
- Turn point pushed towards the camera so it stays centred on screen
- Material copies made for the prefab are destroyed with the magnet

MagnetAnimSettings.cs — [NEW]
- Serializable settings for the magnet anim: prefab, pose, field shader, flight/spin/drop durations and easing
- SpinTurns accepts whole turns only so the magnet lands facing its starting direction

BoosterLineupConfig.cs — [MOD]
- Added Magnet / Vacuum pull fields: PullSeconds, PullCurve, PullFlightSeconds, PullFlightJitter, VacuumStaggerSeconds, PullFrameClearance
- Added PullProgress(t) helper that evaluates PullCurve clamped to 0..1
- Added MagnetAnim (MagnetAnimSettings) section

----------------------------------------------------------------------

3. Picture / Sand

PictureController.cs — [MOD]
- Added optional flightTime on grains (0 keeps the config value)
- TakeGrains uses a quickselect (SelectNearest) to pick the nearest grains instead of sorting the whole colour every frame
- Grains taken by a booster now reach the shared suction sound counter

SandEmissionQueue.cs — [MOD]
- Skipped grains in a batch are credited at the slowest grain's flight time instead of the config flight time

SandParticleEmitter.cs — [MOD]
- Particle start lifetime uses the grain's own flightTime when set

----------------------------------------------------------------------

4. UI Layer

BoosterBar.cs — [MOD]
- Added TryGetButtonScreenCentre(boosterId) so the magnet can launch from its button

----------------------------------------------------------------------

5. Art / Shaders / Prefabs

MagnetDistortion.shader — [NEW]
- New Percas/MagnetDistortion GrabPass shader: animated rings bend the board behind the magnet with a light glow (Strength, Rings, Speed, Glow)

Magnet.fbx, Magnet.png, Magnet.mat — [NEW]
- Added real magnet model and texture on Percas/UnlitTexture under Arts/Models/Booster

MagnetBooster.prefab — [NEW]
- Magnet prefab rotated 180 degrees about Y so the U opens up and the lit side faces the camera, one unit across, pivot at its middle

----------------------------------------------------------------------

6. Config / ScriptableObjects

BoosterLineupConfig.asset — [MOD]
- Set Magnet anim values (field shader, prefab, rise/spin/drop timings) to match the new fly-in path

----------------------------------------------------------------------

7. Docs

booster.md — [MOD]
- Documented the magnet anim, placeholder vs prefab setup, render queue order against the distortion GrabPass, and the new code files
- Updated the fly-in description to the middle-of-screen spin path and noted pull sound behaviour
```
