# bus-down

```
1. Piece Movement

Scripts/SnakeFlow/PieceMovement/PieceMovementService.cs — [MOD]
- RebindAgents no longer replays the suck-in from the old gate to the new one when a Block is compacted to another slot; a Piece in the Entering state now vanishes on the spot
- Added VanishEntering: stops the enter tween, destroys the Piece, then waits SlotsService.CompactDuration before calling OnEntered, so the clear animation does not start mid-slide from the old slot position
- Stuck detection now also counts time when the agent reached the end of its path but is still outside the gate radius, so it re-paths instead of standing still until the level ends
- Added IsInsideGate(agent), comparing the distance to gatePoint against gateRadius

Scripts/SnakeFlow/PieceMovement/PieceGrid.cs — [MOD]
- GateCell now accepts a cell blocked only by SlotFloorMark as the gate cell, so a Block that was just compacted away but has not slid off yet no longer pushes the gate onto a neighbouring cell outside the suck radius

----------------------------------------------------------------------

2. Columns / Blocks

Scripts/SnakeFlow/Columns/Elements/BlockElement.cs — [MOD]
- Added the IsClearing property exposing the _clearing flag
- Shake now offsets m_Root around _rootBasePosition (captured in Awake) instead of writing the Block transform localPosition, so an inactive Block tapped while sliding to the column head still lands at the right spot
- RestorePose resets m_Root.localPosition to _rootBasePosition, so a Block returned to the pool mid-shake is not offset on its next use
- Tap returns silently when the Block has left the board (in a slot, flying or clearing) or when tap input is locked, so no BLOCK_TAP plays
- Added HasLeftBoard() and IsTapInputEnabled(), the latter reading BlockDispatchService.InputEnabled through ServiceLocator

Scripts/SnakeFlow/Columns/BlockDispatchService.cs — [MOD]
- Slot compaction now waits for both in-flight Blocks to land and SlotsService.HasClearingBlock to be false, so a Block mid-clear is never moved to another slot

----------------------------------------------------------------------

3. Services

Scripts/SnakeFlow/Services/SlotsService.cs — [MOD]
- Added CompactDuration, read from the slots config (0 when config is missing)
- Added HasClearingBlock, true while any slot still holds a Block whose clear animation has not taken off

Scripts/SnakeFlow/Services/SnakeService.cs — [MOD]
- Init returns early when snake spawning is disabled: clears the planner and reapplies the speed multiplier without building the planner grid or prewarming SnakeView per slot, which removes the 12–25 connectivity job rebuilds per second

----------------------------------------------------------------------

4. Controllers

Scripts/SnakeFlow/Controllers/GameController.cs — [MOD]
- Update returns before intro finishes, then calls UpdateLastRound every frame instead of only when the snake stepped or pieces went idle, since the last-round check no longer depends on snake ticks
- Added _failInputLocked plus EndLevelWithFail(), which sets _levelEnded, calls BlockDispatchService.LockInput and fires OnLevelFail; both fail paths now go through it
- Added ReleaseFailInputLock(), called on level start, CancelFail (revive) and OnDestroy, because BlockDispatchService lives across scenes

Scripts/SnakeFlow/Controllers/GameSessionController.cs — [MOD]
- ShowFailedPopupDelayedAsync now waits for SettingsPopup to close before opening FailedLevelPopup, and skips the popup if a Retry from Settings already resolved the fail
- Added WaitForSettingsClosedAsync, which checks HasPushedLayer first to avoid the TryGetPresentation warning, then waits until SettingsPopup is no longer showing

----------------------------------------------------------------------

5. View / UI

Scripts/SnakeFlow/View/DifficultyBannerView.cs — [MOD]
- PlayAsync sets m_Group.blocksRaycasts to true for the duration of the banner sequence and resets it in a finally block, so Settings and HUD cannot be tapped while the banner is on screen
- Documented the new prefab requirements: GraphicRaycaster on the root and a full-screen m_Dim with Raycast Target enabled

Prefabs/UIs/pfb_difficulty_banner.prefab — [MOD]
- Added a GraphicRaycaster to the banner root and enabled Raycast Target on the Dim image

----------------------------------------------------------------------

6. Scene Flow / Boot

Scripts/SceneFlow/LoadingScreen.cs — [MOD]
- Added the m_Logo SkeletonGraphic field
- AnimateProgressAsync extends the fake progress duration to at least the remaining logo animation time, then waits until the logo track 0 has finished playing
- Added GetLogoRemainingTime, computing real seconds left on track 0 from AnimationEnd, AnimationStart, TrackTime and the combined entry/state/graphic time scale

Scripts/SceneFlow/BootstrapLoadingScope.cs — [MOD]
- Added the m_Logo SkeletonGraphic field
- WaitForWarmupAsync now waits for the logo to finish one pass before calling AppWarmupService.Start, so shader warm-up, popup preload and pool prewarm no longer stall the logo animation
- Added IsLogoFinished, treating a missing or disabled logo as finished

Scripts/App/GameContext.cs — [MOD]
- InstallWarmup only registers AppWarmupService and no longer calls Start; the Gameplay load, which waits on warm-up, moves behind the logo as a result

Prefabs/UIs/Popups/pfb_loading_screen.prefab — [MOD]
- Bound m_Logo, switched the active logo object, and pointed the SkeletonGraphic at the new Logo skeleton and material with a 753x514 rect

Scenes/App/Bootstrap.unity — [MOD]

- Bound m_Logo on BootstrapLoadingScope

Art/Animations/Logo/ — [NEW]
```
