1. Services

LevelIntroService.cs — [NEW]
- Added the level-open beat: spin the tree to the angle that shows the most birds broadside, then pitch the camera to a resting angle
- FindBestDelta scans every ScanStepDegrees to maximise summed |sin| of each branch row against the camera forward
- CollectAims measures each branch row from the outer bird's world position; top tier by default, all tiers when IntroUseAllTiers, falls back to lower tiers when the top is empty
- Added Prepare() to lock the spin target and move fly-in birds off-screen before the first frame renders, and Begin() to launch spin, pitch and flights after the loading UI hides
- Added CanFlyIn (birds with only KeyFeature or none), PlaceFlyInStart (park bird past the nearest screen edge, kept parented to its slot) and LaunchFlyIn (per-bird random delay, duration, arc via IntroFlyInRandom) reusing BeginFlight land animation
- Added ResolveDurations so spin and pitch share the longer duration when IntroPitchWithSpin is on, otherwise keep their own

CameraPeekService.cs — [MOD]
- Added RestAngle property so peek clamps around a resting angle instead of 0
- Added SetAngle to set the peek angle straight and apply it
- Reset RestAngle and drag state in Clear; apply every frame so the rest angle survives the layout pose reset

TreeRotateService.cs — [MOD]
- Added SetAngle to set the tree spin angle and drop momentum
- Guarded Apply against a null tree view

LevelReleaseService.cs — [MOD]
- Injected LevelIntroService and BranchBreakService and added both to the Clear teardown

PoolService.cs — [NEW]
- Ported a GameObject pool from mahjong-craze: Register/Spawn/Despawn keyed by prefab, IPoolable spawn/return callbacks, IsSpawned and ClearAllPools
- Added internal PoolBucket queue with a HashSet guard against double-return; skips instances destroyed out from under the pool

VfxService.cs — [NEW]
- Plays pooled one-shot VFX at a world position with optional parent (plus lossy-scale compensation), color tint and particle restart
- Subscribes to BirdLandedSignal: bursts feathers at the bird's skin-bounds center, parented to the tier so it turns with the tree, tinted by the bird color via ColorPaletteSO
- Subscribes to BirdDroppedSignal: bursts the same effect when a bird bottoms out, left in world space

BirdEscapeService.cs — [MOD]
- Reshaped the escape beat: whole flock waits EscapeDipLead after the branch snaps, dips at once, and each bird launches as it bottoms out
- Added EscapeStep struct carrying per-bird shape and speed jitter, drawn once and shared across dip and flight
- Depth and dip duration scale by one factor so all birds fall at one speed and deeper birds take off later
- Replaced GetEscapeHeight with GetEscapeTarget: birds now leave sideways past the nearest horizontal edge, angle varying per bird
- Took ElementScope in the constructor to publish BirdDroppedSignal with the bird's tier

BranchBreakService.cs — [NEW]
- A cleared branch is kept alive through a fall: BeginBreak collects the active visual's two halves, BuildFall drives split-then-fall with per-half jitter
- Each half tumbles on the axis perpendicular to the branch and drifts apart, aiming below the viewport edge measured at its own depth
- Tick pools each branch once its DOTween sequence completes; Clear kills any in-flight falls

BranchClearService.cs — [MOD]
- Injected BranchBreakService; a cleared branch now DetachBranch + Break instead of RemoveBranch, so birds escape first and the branch falls

BoardService.cs — [MOD]
- Split RemoveBranch into DetachBranch (drop from tier, pool the birds, return the branch) so callers can pool the branch later

LevelResultService.cs — [MOD]
- Injected BranchBreakService; IsSettled now also waits for HasBreakingBranches so a falling branch is not read as an empty slot by the lose rules
