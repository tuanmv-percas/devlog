# ant-hustle

```
1. Ant Hole

Assets/Game/Art/Hole (HolePit.shader, Hole.mat, HoleOuter.mat, hole_pit.asset, README.md) — [NEW]
- Imported the hole visual from Ant Frenzy with its original GUIDs: HolePit shader, Hole and HoleOuter materials and the baked hole_pit mesh
- README.md records where the assets come from

Hole.prefab — [NEW]
- Hole prefab without Ant Frenzy's HoleElement / HolePit scripts
- Model rotated -90 on X so the hole mouth faces the camera of the XY board
- Model scale set to 1 (was 0.5 from the Editor, which drew the hole at half of RoadHole.Radius); RoadSpawner now sizes the hole from Radius alone

----------------------------------------------------------------------

2. Conveyor Road

RoadData.cs — [MOD]
- Added RoadHole class with Position (Vector2) and Radius, MinRadius = 0.2
- Added RoadData.Hole; Position is in the same space as the road points (Spline local), not relative to the road centre, so dragging a road point leaves the hole in place
- Default hole Position = road DefaultCenter, default Radius = 0.5 (was 1)
- DefaultCenter changed from private to internal so RoadHole can use it
- Doc comment now states coordinates are Spline local and CameraFit scales/moves the RoadSpawner at runtime

RoadSpawner.cs — [MOD]
- Added hole Transform and holeMeshRadius (1.8) fields; PlaceHole() positions the hole and scales it by Radius / holeMeshRadius
- Hole is hidden while the road is not a closed loop or the level has no hole data
- Added BeltHalfWidth for the Level Editor's hole-touches-belt check
- Added HasShape, GetFitPoints() (world positions of belt and rail mesh vertices, excluding the hole), ResetFit() and ApplyFit(scale, position) for CameraFit
- RebuildMeshes() sets every spline point size to the road scale so belt width and rail offset scale with the centre line

----------------------------------------------------------------------

3. Screen Fit (CameraFit)

CameraFit.cs — [NEW]
- MonoBehaviour on FitArea (RectTransform in an overlay canvas, driven to the safe area by SafePadding); the camera does not move
- Fit() places the dock, splits FitArea at the slot edges into a road region above and a board region below, then fits the board and the road
- PlaceDock(): keeps dock scale 1 and centres the slot row on dockLine (0.2–0.8, default 0.5)
- FitBoard(): anchors the Board parent to the top of the board region and binary-searches a scale in [boardMinScale 0.4, boardMaxScale 1.6] so the Floor fits; border walls may run off screen
- FitRoad(): measures road mesh vertices, searches a scale in [roadMinScale 0.3, roadMaxScale 1.5] and centres the road in the road region (iterated for tilted perspective cameras)
- Per-region Padding in canvas units (board 40/40/40/160, road 30/30/220/30)
- Refits on OnRectTransformDimensionsChange; OnDrawGizmosSelected draws the area, split line, board and road regions

LevelManager.cs — [MOD]
- Added optional cameraFit field; FinalizeLevel() calls cameraFit.Fit() after all spawners have built
- ReloadSpawners() uses GetComponentsInChildren<Spawner>(true) since board spawners now sit under a Board parent

BlockVisual.cs — [MOD]
- PlayJump() tweens localScale from jumpFromScale to jumpToScale, so a block leaving the scaled board lands in the unscaled dock slot at its rest size

DockSpawner.cs — [MOD]
- Doc comment: the dock sits outside the Board parent and is not scaled; CameraFit moves it, so Height only applies without CameraFit

----------------------------------------------------------------------

4. Level Editor

SceneViewRoadHandler.cs — [MOD]
- Added Pick.Hole: road mode drags the hole (Ctrl snaps), with a drag preview
- HitsHole() picks the hole when the mouse is inside its mouth or near its centre
- HoleFits() samples the spline at 96 points and checks the hole centre is inside the loop and its edge clears the belt by half the belt width
- DrawHole() draws the hole outline and centre dot; red when it touches the belt or leaves the loop, orange while dragging
- RebuildFromData() calls CameraFit.Fit() after a committed road edit (not during drag)

RoadPanel.cs — [MOD]
- Added Hole section with delayed Position (x, y) and Radius fields, each committed as one undo step
- Shows a warning when the hole touches the belt or is outside the loop, and a note when the road is not a closed loop
- Reset Circle also moves the hole back to the default circle centre, keeping its radius

SceneViewHud.cs — [MOD]
- Road mode hint now reads "Drag: move point / hole"

Spawner.cs — [MOD]
- Clear() calls DeselectChildren() before DestroyImmediate: drops spawned children from Selection and forces ActiveEditorTracker to rebuild
- Stops MissingReferenceException / SerializedObjectNotCreatableException after domain reload when a spawned object was selected during a level rebuild

ObstacleView.cs — [NEW]
- Static settings ShowObstacles and ShowBadges, stored in EditorPrefs (LevelEditor.ShowObstacles, LevelEditor.ObstacleBadges)

SceneViewObstacleView.cs — [NEW]
- With Obstacles off, turns off every Block's ObstaclesHolder and turns its ModelRoot back on, re-applied on each SceneView Layout; edit mode only, scene objects only, never level data
- Turning Obstacles back on rebuilds the level so obstacles control visibility again
- With Color badges on, draws a label on each block with obstacles: colour swatch plus obstacle names and their int fields (e.g. "Ice 5")

DefaultPanel.cs — [MOD]
- Added DrawObstacleView(): "Obstacles" and "Color badges" toggles in the Brush panel

SceneViewBoardGUI.cs — [MOD]
- Added DrawBadge(world, swatch, text) with a 12px colour swatch and a cached badge GUIStyle

----------------------------------------------------------------------

5. Scene Setup

GridPlaceholderBuilder.cs — [MOD]
- SetupHole() instantiates Hole.prefab under the Spline and wires it to RoadSpawner
- SetupCameraFit() builds the Board parent (Floor, Border, Elements re-parented via FindOrAdoptChild), the overlay canvas, FitArea, SafePadding (influence 0.8) and CameraFit, and wires LevelManager.cameraFit

Game.unity — [MOD]
- Wired the Hole instance, Board parent, FitArea canvas, SafePadding and CameraFit
- Belt / Rail meshes stored in the scene were regenerated on open
```
